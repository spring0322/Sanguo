## 📋 案例研究：部队能量覆盖范围高亮

### 问题描述

**需求：** 鼠标悬停在部队上时，显示该部队的能量覆盖范围

**用户反馈的问题：**
1. 能量覆盖范围计算错误（63118 格，完全崩溃）
2. 选中一个部队后，其他部队的悬停也不显示了

### 错误的实现过程

#### 错误 1：重复造轮子

**错误做法：**
- 创建了 `TroopZocCalculator.cs`，试图重新实现能量传播算法
- 虽然参考了 `MultiSourceInfluenceCalculator.InjectTroopEnergy` 的逻辑
- 但实现有严重的 BUG（无条件加入队列，导致无限循环）

**用户质问：**
> "原本部队能量传播是正常的，怎么到你这就乱七八糟的，直接引用现成的能量传播范围渲染不行吗？"

**教训：**
- 不要重复造轮子
- 直接使用现成的 `GlobalInfluenceMap.ArmyEnergy`
- `InjectTroopEnergy` 已经正确计算了能量传播

#### 错误 2：漏掉关键逻辑

**错误做法：**
```csharp
// ❌ 错误：选中部队后，直接返回，不显示其他部队的悬停
if (this.CurrentTroop != null)
{
    _selectedTroopZocTiles.Clear();
    _lastSelectedTroop = null;
    return;
}
```

**用户反馈：**
> "现在只要选中一个，我再把鼠标移动到其他部队上，其他部队不显示渲染，你是不是抄漏了什么东西"

**原本的 `TroopSurveyPlugin` 逻辑：**
- 没有检查 `this.CurrentTroop != null`
- 只要鼠标悬停在部队上，就显示
- 选中部队后，仍然可以悬停其他部队

**教训：**
- 完整阅读现有代码，不要只看部分
- 不要添加自己的"改进"（如检查 `this.CurrentTroop`）
- 完全复用现有逻辑

#### 错误 3：错误理解需求

**错误理解：**
- "只在鼠标悬停时显示" = "选中部队后不显示任何悬停"

**正确理解：**
- "只在鼠标悬停时显示" = "不要在选中部队后自动显示该部队的能量覆盖范围"
- 但是鼠标悬停在其他部队上时，仍然应该显示那个部队的能量覆盖范围

**教训：**
- 仔细理解需求
- 参考现有功能的行为（`TroopSurveyPlugin` 的行为）
- 不要自作聪明添加额外的限制

### 模板 1：完全复用现有逻辑

```csharp
// ✅ 正确：完全复用 TroopSurveyPlugin 的悬停逻辑
private void UpdateSelectedTroopZoc()
{
    Troop hoveredTroop = null;
    
    // 🔥 完全复用 TroopSurveyPlugin 的逻辑（参考第 13145-13175 行）
    // 注意：不要添加额外的检查（如 this.CurrentTroop）
    
    // 1. 检查是否满足显示条件（天眼模式 或 玩家已知该位置）
    if (Session.GlobalVariables.SkyEye || 
        ((Session.Current.Scenario.CurrentPlayer != null) && 
         Session.Current.Scenario.CurrentPlayer.IsPositionKnown(this.position)))
    {
        // 2. 获取鼠标位置的部队
        hoveredTroop = Session.Current.Scenario.GetTroopByPosition(this.position);
        
        // 3. 检查鼠标是否在右侧栏上
        if (this.Plugins.youcelanPlugin.IsShowing && 
            StaticMethods.PointInRectangle(this.MousePosition, this.Plugins.youcelanPlugin.FrameRectangle))
        {
            hoveredTroop = null;
        }
        
        // 4. 检查部队是否埋伏
        if (hoveredTroop != null && hoveredTroop.Status == TroopStatus.埋伏)
        {
            hoveredTroop = null;
        }
    }
    
    // 处理悬停部队...
}
```
