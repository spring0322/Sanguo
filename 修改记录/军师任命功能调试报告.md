### 2. 优化ScreenManager.cs
```csharp
private void FrameFunction_Faction_AppointAdvisor()  //军师
{
    System.Diagnostics.Debug.WriteLine("[DEBUG] FrameFunction_Faction_AppointAdvisor 开始执行");
    
    this.CurrentPerson = Session.MainGame.mainGameScreen.Plugins.TabListPlugin.SelectedItem as Person;
    System.Diagnostics.Debug.WriteLine($"[DEBUG] 选中的人物: {this.CurrentPerson?.Name}");
    
    if (this.CurrentPerson != null)
    {
        // 通过当前建筑获取所属势力，确保在建筑左键菜单上下文中正常工作
        Faction faction = this.CurrentArchitecture?.BelongedFaction ?? this.CurrentFaction;
        System.Diagnostics.Debug.WriteLine($"[DEBUG] 目标势力: {faction?.Name}");
        
        if (faction != null)
        {
            System.Diagnostics.Debug.WriteLine($"[DEBUG] 任命前军师ID: {faction.AdvisorID}");
            System.Diagnostics.Debug.WriteLine($"[DEBUG] 任命前军师: {faction.Advisor?.Name ?? "无"}");
            
            // 设置军师ID
            faction.AdvisorID = this.CurrentPerson.ID;
            
            // 调用任命方法（内部会处理缓存刷新）
            faction.AppointAdvisor(this.CurrentPerson);
            
            System.Diagnostics.Debug.WriteLine($"[DEBUG] 任命后军师ID: {faction.AdvisorID}");
            System.Diagnostics.Debug.WriteLine($"[DEBUG] 任命后军师: {faction.Advisor?.Name ?? "无"}");
            System.Diagnostics.Debug.WriteLine("[DEBUG] 任命完成");
        }
        else
        {
            System.Diagnostics.Debug.WriteLine("[DEBUG] 错误：目标势力为空");
        }
    }
    else
    {
        System.Diagnostics.Debug.WriteLine("[DEBUG] 错误：未选中任何人物");
    }
}
```

## 测试建议

- 运行游戏时打开调试输出窗口
- 查看 `[DEBUG]` 开头的日志信息
- 确认每个步骤是否正常执行

### 2. 测试步骤
1. 进入游戏，选择一个有人物的城池
2. 左键点击城池，选择"军师" -> "任命"
3. 观察是否弹出候选人列表
4. 选择一个候选人，点击确定
5. 检查军师是否成功任命

### 3. 可能的问题点
- 如果没有弹出候选人列表：检查势力是否有合适的候选人（智力>=70）
- 如果弹出列表但点击确定无效：检查FrameFunction调用是否正常
- 如果任命后军师没有变化：检查Faction.Advisor属性缓存是否正确刷新
