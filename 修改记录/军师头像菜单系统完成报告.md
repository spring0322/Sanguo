# 军师头像菜单系统完成报告

## 任务概述
完成军师头像菜单系统的实现，从自定义菜单系统迁移到原生ContextMenuPlugin系统，解决多次绘制问题。

## 已完成的工作

### 1. 清理自定义菜单系统
- **文件**: `WorldOfTheThreeKingdoms/GameScreens/MainGameScreen.cs`
- **操作**: 移除了所有自定义菜单相关的代码
  - 删除了 `AdvisorMenuButton` 结构体
  - 删除了 `AdvisorMenuAction` 枚举
  - 删除了 `ShowAdvisorMenu()`, `HideAdvisorMenu()`, `CreateAdvisorMenuButtons()` 等方法
  - 删除了 `HandleAdvisorMenuClick()`, `ExecuteAdvisorMenuAction()`, `DrawAdvisorMenu()` 等方法
  - 删除了相关的静态字段和纹理缓存

### 2. 简化头像点击处理
- **方法**: `HandleAdvisorPortraitClick()`
- **改进**: 简化为只使用原生ContextMenuPlugin系统
- **功能**: 
  - 检测头像区域点击
  - 显示/隐藏ContextMenu
  - 设置菜单类型为"AdvisorPortrait"

### 3. 添加ContextMenu条件支持
- **新增方法**: `HasAdvisor()`
- **用途**: 为ContextMenu的DisplayIfTrue条件提供支持
- **逻辑**: 检查当前玩家是否有军师 (`Session.Current?.Scenario?.CurrentPlayer?.AdvisorID > 0`)

### 4. 完善菜单结果处理
- **文件**: `WorldOfTheThreeKingdoms/GameScreens/MGSContextMenu.cs`
- **新增方法**: `CreateAdvisorDismissalDialogue()`
- **功能**: 生成罢免军师的对话内容，根据关系类型生成不同对话

### 5. 菜单配置完整性
- **文件**: `Content/Data/Plugins/ContextMenuData.xml`
- **配置**: AdvisorPortrait菜单已配置完整
  - 任命 (AdvisorPortrait_Appoint)
  - 罢免 (AdvisorPortrait_Dismiss) - 带HasAdvisor条件
  - 信息 (AdvisorPortrait_Info)
  - 谏言 (AdvisorPortrait_Advice) - 带HasAdvisor条件

### 6. 枚举定义完整性
- **文件**: `WorldOfTheThreeKingdoms/GameGlobal/ContextMenuResult.cs`
- **枚举**: 军师头像菜单选项已定义
  - `AdvisorPortrait_Appoint`
  - `AdvisorPortrait_Dismiss`
  - `AdvisorPortrait_Info`
  - `AdvisorPortrait_Advice`

## 系统架构

### 原生ContextMenuPlugin集成
```
用户点击头像 → HandleAdvisorPortraitClick() → ContextMenuPlugin.SetMenuKindByName("AdvisorPortrait") 
→ ContextMenu显示 → 用户选择菜单项 → HandleContextMenuResult() → 执行对应功能
```

### DisplayIfTrue条件系统
- `HasAdvisor()` 方法提供条件检查
- ContextMenu自动调用此方法决定菜单项是否显示
- 罢免和谏言功能只在有军师时显示

### 对话系统集成
- 使用现有的DialogueEntry, DialogueType, RelationType类型
- 根据君主与军师的关系生成不同对话内容
- 支持Love, Hate, None三种关系类型
