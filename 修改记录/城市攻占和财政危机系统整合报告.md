# 城市攻占和财政危机系统整合报告

## 📋 项目概述

本次整合基于现有代码结构，添加了两个重要的游戏机制：
1. **城市攻占时的人物命运判定系统**
2. **财政危机时的紧急征收系统**

## 🎯 整合原则

### ✅ **严格遵循现有代码结构**
- 使用原版的 `Captive.Create()` 方法创建俘虏
- 使用原版的 `DecreaseMorale()` 方法降低民心
- 使用原版的 `DecreasePopulation()` 方法减少人口
- 使用原版的 `Person.ChangeFaction()` 方法转换势力

### ✅ **不添加不存在的机制**
- 没有创建新的叛军生成系统
- 没有添加城市声誉属性
- 直接使用现有的 `Morale` 属性代表治安/民心
- 直接产生结果而不是复杂的中间过程

## 🔧 核心系统设计

### **1. 城市攻占人物命运系统**

#### **四种命运类型**
```csharp
public enum FateType 
{ 
    Flee,       // 突围逃跑（原版逻辑处理）
    Surrender,  // 主动投降（转换势力）
    Resign,     // 弃官下野（变成在野）
    Captured    // 突围失败（成为俘虏）
}
```

#### **判定流程**
1. **熔断机制**：义兄弟、高义理武将直接选择突围
2. **仇恨检查**：有仇恨记录的武将拒绝投降
3. **投降判定**：基于忠诚度、性格、关系的综合评分
4. **逃跑检定**：基于武力、忠诚度、仇恨的突围成功率

#### **关键特性**
- **历史真实感**：关羽绝不会投降曹操
- **性格驱动**：野心家容易倒戈，义士宁死不屈
- **能力影响**：武力高的武将更容易突围成功
- **关系网络**：朋友在敌方会增加投降概率

### **2. 财政危机紧急征收系统**

#### **触发条件**
- 势力资金为负数时自动触发
- 基于城市民心状况决定后果

#### **征收机制**
```csharp
// 征收金额 = 基础金额 + 太守能力修正
int baseLevy = Math.Max(500, architecture.Population / 50);
float efficiency = (prefect.Politics + prefect.Intelligence) / 200f;
int goldSeized = (int)(baseLevy * (0.5f + efficiency * 0.5f));
```

#### **后果系统**
- **民心下降**：使用 `DecreaseMorale()` 方法
- **人口流失**：使用 `DecreasePopulation()` 方法
- **太守反应**：基于性格特质的忠诚度变化
- **暴乱后果**：民心过低时的严重后果

### **2. 使用的原版API**

#### **俘虏系统**
- `Captive.Create(person, attackerFaction)` - 创建俘虏
- `person.SetBelongedCaptive()` - 设置俘虏状态（自动调用）

#### **势力转换**
- `person.ChangeFaction(faction)` - 武将转换势力
- `person.Status = PersonStatus.NoFaction` - 武将下野

#### **城市属性修改**
- `architecture.DecreaseMorale(amount)` - 降低民心
- `architecture.DecreasePopulation(amount)` - 减少人口
- `architecture.BelongedFaction.Gold += amount` - 增加势力资金

#### **武将属性修改**
- `person.Loyalty += change` - 修改忠诚度
- `person.Die()` - 武将死亡

## 🎮 游戏体验提升

### **1. 攻城战的丰富性**
- **意外收获**：攻城可能获得投降的敌将
- **策略考量**：是否值得攻打有名将的城市
- **历史感**：符合三国历史中的人物行为

### **2. 财政管理的深度**
- **应急机制**：防止AI因财政问题瘫痪
- **风险权衡**：短期收益vs长期民心损失
- **真实感**：模拟历史上的苛政后果

### **3. 人物性格的重要性**
- **投降倾向**：野心家vs忠臣的不同选择
- **太守反应**：不同性格对强征的不同态度
- **关系网络**：朋友关系影响投降决策

## 📈 平衡性设计

### **1. 投降率控制**
- **高忠诚(80+)**：约5-10%投降率
- **中忠诚(50-80)**：约15-30%投降率
- **低忠诚(<50)**：约40-60%投降率

### **2. 逃跑成功率**
- **武将(武力85+)**：约65-80%成功率
- **文官(武力30-)**：约30-45%成功率
- **忠臣(忠诚95+)**：额外+10%成功率

### **3. 强征后果**
- **民心损失**：征收金额/100，最多30点
- **人口流失**：5%正常，15%暴乱时
- **太守反应**：-8到+2忠诚度变化
