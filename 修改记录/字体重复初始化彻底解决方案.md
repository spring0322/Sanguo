### 1. TextManager.Init() 防重复机制

```csharp
public class TextManager
{
    // [新增] 防重复初始化标志
    private static bool _isInitializing = false;
    private static string _lastInitializedFont = "";
    
    public static void Init(string name, int size)
    {
        lock (lockObj)
        {
            // 检查是否正在初始化
            if (_isInitializing)
            {
                Debug.WriteLine("[TextManager] 跳过重复初始化请求");
                return;
            }
            
            // 检查是否已经初始化了相同的字体
            string fontKey = $"{name}_{size}";
            if (font != null && _lastInitializedFont == fontKey)
            {
                Debug.WriteLine("[TextManager] 字体已存在，跳过初始化");
                return;
            }
            
            _isInitializing = true;
        }
        
        try
        {
            // 正常的初始化逻辑...
            Debug.WriteLine($"[TextManager] 开始初始化字体: {name}");
            // ...
            _lastInitializedFont = fontKey;
        }
        finally
        {
            _isInitializing = false;
        }
    }
}
```

### 2. Session.LoadFont() 智能重载

```csharp
public static void LoadFont(string language)
{
    // [新增] 检查是否真的需要重新加载
    FontPair newFontPair = GetFontPairForLanguage(language);
    
    bool needReload = (CacheManager.FontPair.Name != newFontPair.Name || 
                      CacheManager.FontPair.Size != newFontPair.Size);
    
    CacheManager.FontPair = newFontPair;
    
    // [修改] 只有在字体配置真的改变时才重置
    if (needReload)
    {
        TextManager.font = null;
        Debug.WriteLine("[Session] 字体配置改变，重置字体");
    }
    else
    {
        Debug.WriteLine("[Session] 字体配置未改变，保持现有字体");
    }
}
```

## 🛡️ 防护机制

### 1. 并发保护
- 使用 `lock` 确保线程安全
- 防止多个线程同时初始化字体

### 2. 重复检测
- 记录最后初始化的字体信息
- 相同字体不会重复加载

### 3. 状态跟踪
- `_isInitializing` 标志防止递归调用
- `_lastInitializedFont` 记录已加载的字体

### 4. 智能重载
- 只有在字体配置真正改变时才重置
- 避免不必要的字体重新加载
