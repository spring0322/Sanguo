# 军师对话轮流显示修复完成

## 🔍 问题诊断

用户反馈对话仍然"挤在一起"，没有实现轮流显示效果。经过分析发现：

### 根本原因
`ScreenManager.cs` 中的 `FrameFunction_Faction_AppointAdvisor` 方法直接调用了 `faction.AppointAdvisor()`，而没有使用我们实现的 `AdvisorAppointmentSystem.TryAppointAdvisor()` 方法。

### 问题流程
1. 用户点击军师头像菜单中的"任命"选项
2. 系统调用 `FrameFunction_Faction_AppointAdvisor()`
3. 该方法直接调用 `faction.AppointAdvisor()` - **跳过了轮流对话系统**
4. 结果：没有显示任何对话，或显示的是旧的合并对话

## ✅ 修复方案

### 修改的文件
**WorldOfTheThreeKingdoms/GameScreens/ScreenManager.cs**

### 修改内容
将 `FrameFunction_Faction_AppointAdvisor` 方法中的直接任命调用：

```csharp
// 旧代码 - 直接任命，没有对话
faction.AppointAdvisor(this.CurrentPerson);
```

替换为使用轮流对话系统：

```csharp
// 新代码 - 使用AdvisorAppointmentSystem，显示轮流对话
bool success = GameManager.AdvisorAppointmentSystem.TryAppointAdvisor(
    faction.Leader, 
    this.CurrentPerson, 
    faction
);
```

## 🎯 修复效果

现在当用户任命军师时：

1. **第一步**: 显示君主的对话和头像
   - 例如："今欲请足下担任军师一职，不知尊意如何？"
   
2. **用户点击继续**

3. **第二步**: 显示军师的回应和头像
   - 例如："承蒙主公信任，在下定当竭尽全力！"

4. **用户点击完成**: 对话结束，任命完成

## 🔧 技术细节

### 调用链路
```
用户点击"任命" 
→ ContextMenu处理 
→ FrameFunction_Faction_AppointAdvisor() 
→ AdvisorAppointmentSystem.TryAppointAdvisor() 
→ ShowAlternatingDialogue() 
→ 轮流显示对话
```

### 支持的功能
- ✅ 轮流显示君主和军师对话
- ✅ 根据人物属性匹配不同对话
- ✅ 支持特殊人物组合对话（如刘备+诸葛亮）
- ✅ 同权重对话随机选择
- ✅ 拒绝任命的对话处理
- ✅ 完整的错误处理和调试信息
