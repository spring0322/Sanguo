# 军师谏言事件系统说明

## 概述

军师谏言系统已从菜单形式改为事件弹窗形式，每回合自动检查并显示最重要的谏言，提供更沉浸式的游戏体验。

## 系统特性

### 🎯 事件弹窗形式
- 采用类似事件弹窗的形式显示谏言
- 使用游戏原生的 `tupianwenziPlugin` 对话系统
- 显示军师头像和对话内容

### ⏰ 每回合自动触发
- 在每日开始时（`Date_OnDayStarting`）自动检查
- 每回合最多显示一个谏言
- 避免信息过载，保持游戏节奏

### 📊 优先级机制
按以下优先级顺序检查谏言：
1. **敌军来袭预警** - 最高优先级
2. **人才招募建议** - 中等优先级  
3. **忠诚度警告** - 较低优先级

### 🔄 智能去重
- **敌军预警去重**: 同一支敌军只报告一次
- **日期去重**: 同一天不重复检查
- **缓存管理**: 自动清理已销毁的敌军记录

## 功能详解

### 1. 敌军来袭预警 🚨

**触发条件**:
- 检测范围内有敌对部队
- 检测范围 = 军师智力 ÷ 10

**去重机制**:
- 记录已警告的敌军ID
- 同一支敌军不重复报告
- 新出现的敌军会触发新的警告

**谏言示例**:
```
军师 诸葛亮 求见：

主公，据某观察，敌军正在向我方逼近！请速做防备！
```

### 2. 人才招募建议 👥

**触发条件**:
- 发现能力值总和 > 200 的在野武将
- 计算公式：统率 + 智力 + 政治 + 魅力 > 200

**对话后跳转**:
- 自动显示推荐的在野武将列表
- 按能力值排序，最多显示10名
- 使用 `ShowTabListInFrame` 显示招募界面

**谏言示例**:
```
军师 周瑜 求见：

主公，某发现附近有贤才在野，建议派人前去招揽！

（对话结束后将显示推荐人选）
```

### 3. 忠诚度警告 ⚠️

**触发条件**:
- 发现忠诚度 < 60 的武将（排除君主）
- 军师智力影响发现概率

**对话后跳转**:
- 自动显示低忠诚武将列表
- 按忠诚度从低到高排序
- 使用 `ShowTabListInFrame` 显示人物详情

**谏言示例**:
```
军师 荀彧 求见：

主公，某观察到部分将领忠诚度有所下降，需多加关注！

（对话结束后将显示相关武将）
```

## 准确率系统

### 智力影响准确性
- 军师智力越高，谏言越准确
- 智力100：必定准确
- 智力70-99：线性递增准确率

### 不准确谏言示例
当军师判断失误时，会给出相反的建议：

**敌军误报**:
```
军师 普通谋士 求见：

主公，某观察四周，暂无异常，可安心发展。
```

**人才误判**:
```
军师 低智谋士 求见：

主公，当前人才济济，暂无招揽之需。
```

## 性能优化

### 1. 缓存机制
- 避免同一天重复检查
- 缓存已警告的敌军
- 减少不必要的计算

### 2. 智能触发
- 只在有军师时检查
- 按优先级顺序检查，找到即停止
- 异常处理确保系统稳定

### 3. 内存管理
- 定期清理无效缓存
- 游戏加载时重置状态
- 避免内存泄漏

## 用户体验

### 优势
✅ **沉浸式体验**: 事件弹窗更符合游戏氛围  
✅ **信息精准**: 每回合只显示最重要的谏言  
✅ **操作便捷**: 对话后直接跳转到相关界面  
✅ **智能去重**: 避免重复信息干扰  
✅ **准确率系统**: 军师智力影响谏言质量  

### 改进点
- 不再需要手动点击查看谏言
- 避免了菜单操作的繁琐
- 提供了更直接的后续操作

## 扩展性

系统设计具有良好的扩展性：

1. **新建议类型**: 在枚举中添加新类型，实现对应检查方法
2. **新跳转逻辑**: 在 `HandleAdviceCallback` 中添加新的处理分支
3. **新触发条件**: 修改 `GetHighestPriorityAdvice` 的检查逻辑
4. **新显示效果**: 自定义 `GetAdviceEventImage` 和文本生成

## 注意事项

1. **军师依赖**: 必须有军师才会触发谏言
2. **优先级**: 敌军预警优先级最高，会覆盖其他建议
3. **去重逻辑**: 敌军预警有去重机制，其他建议每次都可能触发
4. **性能影响**: 每日检查会有轻微性能开销，但已优化
5. **UI兼容**: 使用原生对话系统，兼容性良好

这个新的谏言事件系统提供了更加自然和沉浸式的游戏体验，让玩家能够更好地感受到军师的存在和价值。
