## ✅ 问题根源与修复

### 1. 绘制区域无效错误修复

**根本原因**：部队标题插件中的士气条宽度计算可能返回0

**问题代码**：
```csharp
private int shiqitiaokuandu(Troop troop)
{
    return troop.Army.Morale * this.shiqitiaoweizhi.Width / troop.Army.MoraleCeiling;
}
```

**修复方案**：
```csharp
private int shiqitiaokuandu(Troop troop)
{
    // 修复：确保士气条宽度至少为1像素，避免绘制区域无效错误
    if (troop.Army.MoraleCeiling <= 0)
    {
        return 1; // 如果士气上限为0，返回1像素宽度
    }
    
    int width = troop.Army.Morale * this.shiqitiaoweizhi.Width / troop.Army.MoraleCeiling;
    return Math.Max(1, width); // 确保宽度至少为1像素
}
```

**修复文件**：
- `WorldOfTheThreeKingdoms/GamePlugins/TroopTitlePlugin/TroopTitle.cs`
- `WorldOfTheThreeKingdoms/GamePlugins/ArchitectureDetail/ArchitectureDetail.cs`

### 2. 对话框不显示问题修复

**根本原因**：错误使用了tupianwenziPlugin的SetGameObjectBranch方法

**问题分析**：
- 原代码使用了4参数版本，但参数顺序和用法不正确
- tupianwenziPlugin需要使用6参数版本来正确显示自定义文本

**修复前代码**：
```csharp
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker,                    // 说话人
    null,                       // 游戏对象
    advice.AdvisorComment,      // 文本内容
    ""                          // 额外文本
);
```

**修复后代码**：
```csharp
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker,                    // 说话人
    null,                       // 游戏对象
    advice.AdvisorComment,      // 分支名称/文本内容
    "AdvisorAdvice.jpg",        // 背景图片
    "",                         // 音效文件
    ""                          // 额外显示文本
);
```

## 🎯 技术要点总结

### 1. tupianwenziPlugin正确用法
- 使用6参数版本：`SetGameObjectBranch(person, gameObject, branchName, tupian, shengyin, TryToShowString)`
- branchName可以是分支名称或直接的文本内容
- 必须设置背景图片参数，即使是空字符串

### 2. 绘制区域无效错误预防
- 所有进度条、状态条的宽度/高度计算都要使用`Math.Max(1, calculatedValue)`
- 特别注意除法运算可能导致的0值
- 在返回Rectangle之前验证尺寸有效性

### 3. 回调机制
- 使用`SetCloseFunction`设置对话框关闭后的处理逻辑
- 回调函数中处理后续的游戏流程
- 确保回调函数中的异常处理
