# 军师对话性格类型筛选修复完成

## ✅ 问题解决

**原问题**: `Entry Type="Default" LeaderKind="635" AdvisorKind="289"` 这段应该是诸葛亮专属的，但其他人也用出来了

**根本原因**: 性格类型（LeaderKind/AdvisorKind）的筛选逻辑不够严格，只是加分而不是排除性筛选

## 🔧 技术修复

### 修复前的问题逻辑
```csharp
// 原来的逻辑 - 只是加分，不排除
if (LeaderKind != -1 && leader.Character?.ID == LeaderKind)
{
    score += 50; // 只是加分，其他人仍然可能使用
}
```

### 修复后的严格筛选
```csharp
// 新的逻辑 - 严格筛选
if (LeaderKind != -1)
{
    if (leader.Character?.ID == LeaderKind)
    {
        score += 50; // 君主性格匹配
    }
    else
    {
        return 0; // 指定了君主性格但不匹配，直接淘汰
    }
}
```

## 🎯 筛选规则

### 1. 双重性格筛选
- `LeaderKind="635" AdvisorKind="289"` 表示只有性格ID为635的君主任命性格ID为289的军师时才能使用
- 必须君主和军师的性格ID都完全匹配

### 2. 单一性格筛选
- `LeaderKind="635"` 表示只有性格ID为635的君主才能使用
- `AdvisorKind="289"` 表示只有性格ID为289的军师才能使用

### 3. 严格排除机制
- 如果指定了性格要求但不匹配，该对话条目会被直接淘汰（返回0分）
- 其他人无法使用专属对话

## 📊 优先级系统

1. **双重ID匹配**: LeaderID + AdvisorID = 200分
2. **双重性格匹配**: LeaderKind + AdvisorKind = 100分  
3. **单一ID匹配**: LeaderID 或 AdvisorID = 100分
4. **单一性格匹配**: LeaderKind 或 AdvisorKind = 50分
5. **属性匹配**: 智力、年龄、忠诚度等 = 10-20分
