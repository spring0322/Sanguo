# 军师推荐系统异常修复报告

## 问题描述

用户报告在军师谏言系统中，当招募成功后点击确定时会发生异常崩溃：

```
[军师谏言] 选中武将: 诸葛亮
[招募操作] 武将 诸葛亮 已加入势力 刘备，当前忠诚度: 0
[军师谏言] 成功招募武将: 诸葛亮
[招募结果] 显示结果: 成功=True, 武将=诸葛亮
引发的异常:"System.Exception"(位于 WorldOfTheThreeKingdoms.exe 中)
选中人点确定就跳出了
```

## 问题分析

通过分析代码发现问题出现在 `AdvisorRecommendationSystem.cs` 的 `ShowRecommendationDialog` 方法中：

### 根本原因

在调用 `xianshishijiantupian` 方法时，参数不匹配导致异常：

**错误的调用方式：**
```csharp
Session.MainGame.mainGameScreen.xianshishijiantupian(
    faction.Advisor, 
    talent.Name,           // 错误：应该传递完整消息
    TextMessageKind.SearchPersonFound, 
    "AdvisorRecommendation", 
    "", 
    "", 
    true
);
```

**正确的方法签名：**
```csharp
public override void xianshishijiantupian(Person p, string TextResultString, TextMessageKind msgKind, string shijian, string tupian, string shengyin, bool zongshixianshi)
```

### 问题详情

1. **参数类型不匹配**：传递了 `talent.Name`（武将名字）而不是完整的消息文本
2. **消息内容丢失**：应该显示完整的推荐结果消息，而不仅仅是武将名字
3. **用户体验问题**：异常导致游戏崩溃，影响正常游戏流程

## 修复方案

### 修复内容

修改 `AdvisorRecommendationSystem.cs` 第534-544行的 `ShowRecommendationDialog` 方法：

**修复前：**
```csharp
Session.MainGame.mainGameScreen.xianshishijiantupian(
    faction.Advisor, 
    talent.Name, 
    TextMessageKind.SearchPersonFound, 
    "AdvisorRecommendation", 
    "", 
    "", 
    true
);
```

**修复后：**
```csharp
Session.MainGame.mainGameScreen.xianshishijiantupian(
    faction.Advisor, 
    message,         // 使用完整的消息文本
    TextMessageKind.SearchPersonFound, 
    "AdvisorRecommendation", 
    "", 
    "", 
    true
);
```

### 修复效果

1. **消除异常**：修复参数不匹配问题，防止游戏崩溃
2. **完整消息显示**：现在会显示完整的推荐结果消息，包括：
   - 成功招募的祝贺信息
   - 武将能力详情
   - 初始忠诚度信息
3. **改善用户体验**：玩家可以正常查看推荐结果，不会被异常中断
