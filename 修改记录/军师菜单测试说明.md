# 军师菜单集成测试说明

## 修改内容

1. **菜单配置** (ContextMenuData.xml)
   - 在"君主"菜单下添加了"军师管理"子菜单
   - 包含"任命军师"和"罢免军师"两个选项

2. **枚举定义** (ContextMenuResult.cs)
   - 添加了 `Monarch_AdvisorManagement_AppointStrategist`
   - 添加了 `Monarch_AdvisorManagement_RecallStrategist`

3. **菜单处理** (MGSContextMenu.cs)
   - 添加了对新菜单项的处理逻辑
   - 使用 goto 语句重用现有的军师任命/罢免代码

4. **StrategistUI 禁用**
   - 禁用了独立的军师按钮绘制和更新
   - 用户现在需要通过建筑菜单访问军师功能

## 测试步骤

1. 启动游戏
2. 点击任意己方建筑
3. 在弹出的建筑菜单中找到"君主"选项
4. 在"君主"子菜单中找到"军师管理"
5. 点击"军师管理"应该看到：
   - "任命军师" (如果当前没有军师或可以重新任命)
   - "罢免军师" (如果当前有军师)

## 预期结果

- 不再有独立的军师按钮在屏幕上显示
- 军师功能完全集成到建筑菜单系统中
- 点击"任命军师"应该弹出候选人选择界面
- 点击"罢免军师"应该执行罢免操作

## 菜单路径

建筑左键菜单 → 君主 → 军师管理 → 任命军师/罢免军师
