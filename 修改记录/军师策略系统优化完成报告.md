## 技术实现细节

### 核心方法实现
```csharp
public void TriggerAdvisorAdvice(GameManager.StrategyKind strategy, object target = null)
{
    // A. 获取当前玩家势力
    var faction = Session.Current.Scenario.CurrentPlayer;
    if (faction == null) return;

    // B. 获取军师（如果没有军师，尝试用君主代替）
    Person advisor = faction.Advisor;
    Person speaker = advisor ?? faction.Leader;
    if (speaker == null) return;

    // C. 核心：调用算法获取结果
    var advice = _advisorStrategy.GetAdvice(speaker, faction, target, strategy);

    // D. 核心：强制弹窗显示
    this.xianshishijiantupian(
        speaker, 
        advice.AdvisorComment, 
        TextMessageKind.SearchPersonFound, 
        "AdvisorStrategy", 
        "", 
        "", 
        true // 暂停游戏等待玩家点击
    );
}
```

### 关键优化点

1. **容错处理**：优雅处理无军师情况，使用君主代替
2. **参数简化**：`xianshishijiantupian` 调用参数更加简洁
3. **统一接口**：所有策略类型使用相同的调用方式
4. **目标支持**：预留目标参数，支持未来扩展
