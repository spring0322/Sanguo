# 忠诚度风险控制系统补丁报告

## 概述

成功为人事管理系统添加了关键的忠诚度和稳定性评估机制。该补丁实现了智能的风险控制系统，能够识别和处理危险武将，防止叛变和独立，确保政权稳定。

## 核心功能

### 1. 稳定性评估系统

**CalculateStabilityScore() 方法：**
- **评分范围**：0.05 ~ 1.0
- **1.0**：绝对安全（如诸葛亮）
- **0.1**：极其危险（如吕布、魏延）

**评估维度：**

#### 基础忠诚度 (Loyalty)
```csharp
if (officer.Loyalty < 90)
{
    stability *= (officer.Loyalty / 100f); // 忠诚60 → 系数0.6
}
```

#### 野心惩罚 (Ambition)
```csharp
if (officer.Ambition > 70)
{
    float ambitionPenalty = (officer.Ambition - 70) * 0.01f;
    stability -= ambitionPenalty; // 野心100 → 扣除0.3
}
```

#### 义理修正 (Righteousness)
```csharp
if (officer.Righteousness < 40)
{
    stability *= 0.7f; // 义理低 → 直接打7折
}
```

#### 厌恶关系 (Dislike)
```csharp
if (officer.Dislikes(_faction.Ruler))
{
    stability *= 0.1f; // 厌恶君主 → 绝不能让他掌权
}
```

#### 性格特质影响
```csharp
if (officer.Traits.Contains(Trait.Loyal)) stability *= 1.2f;      // 忠诚加成
if (officer.Traits.Contains(Trait.Rebellious)) stability *= 0.5f; // 叛逆扣分
```

### 2. 清洗机制 (Purge Phase)

**PurgeRiskyPrefects() 方法：**
- 在每次人事更新前执行
- 自动识别和解除危险太守职务
- 将危险武将召回首都软禁

**危险武将判定标准：**
```csharp
private bool IsOfficerRisky(Officer officer)
{
    bool lowLoyaltyHighAmbition = (officer.Loyalty < 80 && officer.Ambition > 70);
    bool veryLowLoyalty = (officer.Loyalty < 60);
    bool lowRighteousness = (officer.Righteousness < 30);
    bool dislikesRuler = (officer.Dislikes(_faction.Ruler));
    bool hasRebelliousTrait = officer.Traits.Contains(Trait.Rebellious);
    
    return lowLoyaltyHighAmbition || veryLowLoyalty || lowRighteousness || 
           dislikesRuler || hasRebelliousTrait;
}
```

### 3. 分级任命标准

**IsSuitableForImportantPosition() 方法：**

#### 忠诚度要求
- **普通城市**：忠诚度 ≥ 70
- **边境城市**：忠诚度 ≥ 75
- **首都**：忠诚度 ≥ 85

#### 稳定性要求
- **普通城市**：稳定性 ≥ 0.6
- **首都**：稳定性 ≥ 0.8

### 4. 风险修正评分

**军事评分修正：**
```csharp
private float CalculateMilitaryScore(Officer officer, float threatLevel)
{
    float rawScore = officer.Leadership * 2.0f + officer.War * 1.5f + officer.Intelligence * 0.8f;
    // ... 性格和经验修正 ...
    
    // === 风险修正 ===
    float stability = CalculateStabilityScore(officer);
    return rawScore * stability; // 能力 × 稳定性
}
```

**内政评分修正：**
```csharp
private float CalculateDomesticScore(Officer officer, City city)
{
    float rawScore = officer.Politics * 2.0f + officer.Intelligence * 1.0f + officer.Leadership * 0.5f;
    // ... 性格和经验修正 ...
    
    return rawScore * CalculateStabilityScore(officer); // 内政太守独立风险同样很高
}
```

```
忠诚度：70, 野心：85, 义理：50  
性格特质：莽撞

适合职位：普通前线城市，不适合首都
```

```

```

## 战术应用

### 1. 预防叛变
- **自动识别**：系统自动识别潜在叛变者
- **提前处理**：在叛变发生前解除职务
- **软禁机制**：将危险武将召回首都控制

### 2. 分级管理
- **首都**：只任命最忠诚的武将（忠诚≥85，稳定性≥0.8）
- **前线**：平衡能力和忠诚度（忠诚≥75）
- **后方**：相对宽松但仍有底线（忠诚≥70）

### 3. 动态调整
- **忠诚度变化**：系统会根据忠诚度变化动态调整
- **关系恶化**：如果武将开始厌恶君主，立即处理
- **性格影响**：叛逆性格的武将受到严格监控

## 性能影响

### 计算复杂度
