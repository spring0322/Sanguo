# 防腐系统完整使用指南

## 🎯 防腐系统概述

**防腐 (Anti-Corruption) 系统**的核心思想是：
- **JSON中保持拼音字段**：兼容现有数据格式
- **C#代码中使用英文属性**：提升代码可读性和维护性
- **自动映射转换**：通过 `JsonProperty` 特性实现无缝转换

## 🔧 核心原理

### **问题：拼音属性名的困扰**
```csharp
// ❌ 丑陋的拼音代码
int damage = disaster.minxinshanghai;  // 什么是minxinshanghai？
int loss = disaster.nongyeshanghai;    // 什么是nongyeshanghai？
int hurt = disaster.shangyeshanghai;   // 什么是shangyeshanghai？
```

### **解决方案：防腐映射**
```csharp
// ✅ 干净的英文代码
int popularityDamage = disaster.PopularityDamage;   // 清晰：民心伤害
int agricultureDamage = disaster.AgricultureDamage; // 清晰：农业伤害
int commerceDamage = disaster.CommerceDamage;       // 清晰：商业伤害
```

## 🏗️ 防腐类设计

### **完整的防腐类示例**
```csharp
public class DisasterEffect
{
    // === 1. 已经是英文的字段，直接对应 ===
    public int ID { get; set; }

    public int FoodDamage { get; set; }    // 粮草伤害
    public int FundDamage { get; set; }    // 资金伤害

    [JsonProperty("minxinshanghai")]      // JSON中的拼音字段
    public int PopularityDamage { get; set; }  // C#中的英文属性

    [JsonProperty("nongyeshanghai")]
    public int AgricultureDamage { get; set; }

    [JsonProperty("shangyeshanghai")]
    public int CommerceDamage { get; set; }

    [JsonProperty("renkoushanghai")]
    public int PopulationDamage { get; set; }

    [JsonProperty("jishushanghai")]
    public int TechnologyDamage { get; set; }

    [JsonProperty("naijiushanghai")]
    public int EnduranceDamage { get; set; }

    [JsonProperty("tongzhishanghai")]
    public int DominationDamage { get; set; }

    // === 3. AI增强方法 ===
    [JsonIgnore]
    public int TotalDamage => PopularityDamage + AgricultureDamage + 
                             CommerceDamage + PopulationDamage + 
                             TechnologyDamage + EnduranceDamage + 
                             DominationDamage;
}
```

```csharp
    if (effectName.Contains("农业"))
    {

        if (context.TerrainType == TerrainType.Plain)
        {
            score += 150f; // 平原地区农业伤害加成

        if (context.TerrainType == TerrainType.City)
        {
            score += 200f; // 城市地区商业伤害加成
        }
    }
```

### **创建防腐工厂类**
```csharp
public static class AntiCorruptionFactory
{
    /// <summary>
    /// 创建防腐映射配置
    /// </summary>
    public static JsonSerializerSettings CreateAntiCorruptionSettings()
    {
        return new JsonSerializerSettings
        {
            // 忽略大小写
            PropertyNameCaseInsensitive = true,
            
            // 忽略空值
            NullValueHandling = NullValueHandling.Ignore,
            
            // 自定义转换器
            Converters = new List<JsonConverter>
            {
                new PinyinToEnglishConverter()
            }
        };
    }

    /// <summary>
    /// 批量加载防腐对象
    /// </summary>
    public static List<T> LoadAntiCorruptionObjects<T>(string jsonContent)
    {
        var settings = CreateAntiCorruptionSettings();
        return JsonConvert.DeserializeObject<List<T>>(jsonContent, settings);
    }
}
```

## 📈 性能优化

### **缓存防腐对象**
```csharp
public class AntiCorruptionCache
{
    private static readonly Dictionary<string, object> _cache = 
        new Dictionary<string, object>();

    public static T GetOrLoad<T>(string key, Func<T> loader)
    {
        if (_cache.TryGetValue(key, out object cached))
        {
            return (T)cached;
        }

        var loaded = loader();
        _cache[key] = loaded;
        return loaded;
    }

    public static List<DisasterEffect> GetDisasters()
    {
        return GetOrLoad("disasters", () =>
        {
            string json = File.ReadAllText("disasters.json");
            return JsonConvert.DeserializeObject<List<DisasterEffect>>(json);
        });
    }
}
```

### **批量处理防腐数据**
```csharp
public class BatchAntiCorruptionProcessor
{
    public void ProcessDisasterBatch(List<string> jsonFiles)
    {
        var allDisasters = new List<DisasterEffect>();

        // 并行处理多个文件
        Parallel.ForEach(jsonFiles, jsonFile =>
        {
            var content = File.ReadAllText(jsonFile);
            var disasters = JsonConvert.DeserializeObject<List<DisasterEffect>>(content);
            
            lock (allDisasters)
            {
                allDisasters.AddRange(disasters);
            }
        });

        // 验证和处理
        foreach (var disaster in allDisasters)
        {
            ValidateDisaster(disaster);
            ProcessDisaster(disaster);
        }
    }
}
```
