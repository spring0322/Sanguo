# 菜单显示和功能修复

## 🎯 发现的问题

### 1. 只显示一个字
从截图看到"势力情报"只显示了最后一个"报"字

**可能原因**:
- 菜单宽度 120px 可能不够显示4个中文字符
- 反射调用 TextManager 时参数可能有问题
- 字体渲染位置计算错误

### 2. 点击后没有功能
点击菜单项只输出日志，没有实际功能

**原因**:
```csharp
OnClick = () => { Console.WriteLine("查看势力情报"); }  // 只是日志
```

## ✅ 修复方案

### 1. 增加菜单宽度
```csharp
// 修复前
private const int MENU_WIDTH = 120; // 可能不够4个中文字符

// 修复后  
private const int MENU_WIDTH = 140; // 足够显示"势力情报"4个字
```

**计算依据**:
- 每个中文字符约 30px (根据 FontPair.Width = 30)
- "势力情报" = 4字符 × 30px = 120px
- 加上左右边距 8px × 2 = 16px
- 总需求: 120 + 16 = 136px
- 设置为 140px 确保充足空间

### 2. 实现真正的功能
```csharp
// 修复前 - 只输出日志
OnClick = () => { Console.WriteLine("查看势力情报"); }

// 修复后 - 调用游戏功能
OnClick = () => { 
    Console.WriteLine("点击了势力情报");
    try
    {
        var mainScreen = Session.MainGame.mainGameScreen;
        if (mainScreen != null && Session.Current.Scenario?.CurrentPlayer != null)
        {
            // 显示当前势力的详细信息界面
            mainScreen.ShowTabListInFrame(
                UndoneWorkKind.Frame, 
                FrameKind.Faction, 
                FrameFunction.Browse, 
                false, true, false, false, 
                Session.Current.Scenario.CurrentPlayer.GetGameObjectList(), 
                null, "势力信息", "");
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine($"显示势力信息失败: {ex.Message}");
    }
}
```

## 🔧 技术细节

### ShowTabListInFrame 参数说明
```csharp
mainScreen.ShowTabListInFrame(
    UndoneWorkKind.Frame,           // 工作类型：框架
    FrameKind.Faction,              // 框架类型：势力
    FrameFunction.Browse,           // 功能：浏览
    false, true, false, false,      // 显示选项
    CurrentPlayer.GetGameObjectList(), // 数据源：当前势力
    null,                           // 选中项：无
    "势力信息",                      // 标题
    ""                              // 副标题
);
```

### 菜单尺寸计算
```
菜单总宽度 = MENU_WIDTH + (MENU_PADDING × 2) = 140 + 16 = 156px
菜单项宽度 = MENU_WIDTH = 140px
文字区域 = 140 - 边距 ≈ 124px (足够4个中文字符)
```
