# 🎮 游戏窗口可见性解决方案

## 🎯 问题描述
游戏进程正常运行，但窗口不可见。这是一个常见的窗口显示问题。

## ✅ 确认的状态
- ✅ 游戏进程正在运行
- ✅ 游戏标题: "中华三国志(v1.25.1) - build-2025-12-15"
- ✅ 所有依赖文件已修复
- ❌ 游戏窗口不可见

## 🔧 解决方案

### 方案1: 使用窗口显示工具 (推荐)
```cmd
show_game_window.bat
```
这个脚本会：
- 自动查找游戏进程
- 强制显示游戏窗口
- 将窗口移动到屏幕中央
- 置顶显示游戏窗口

### 方案2: 手动切换窗口
1. **Alt + Tab**: 按住Alt键，按Tab键切换到游戏窗口
2. **任务栏**: 查看任务栏是否有游戏图标，点击它
3. **右键菜单**: 右键任务栏游戏图标 → 选择"还原"

### 方案3: 使用PowerShell脚本
```powershell
powershell -ExecutionPolicy Bypass -File "bring_game_to_front.ps1"
```

### 方案4: 重新启动游戏
如果以上方法都不行：
```cmd
setup_and_launch_game.bat
```
新版启动脚本包含自动窗口检测功能。

## 🔍 可能的原因

### 1. 窗口在屏幕外
- 游戏可能记住了之前的窗口位置
- 如果之前使用多显示器，窗口可能在已断开的显示器上

### 2. 窗口被最小化
- 游戏启动时自动最小化
- 检查任务栏是否有游戏图标

### 3. 窗口在后台
- 其他程序覆盖了游戏窗口
- 游戏窗口失去焦点

### 4. 显示器配置问题
- 多显示器设置变更
- 分辨率或缩放设置问题

## 🛠️ 详细操作步骤

### 步骤1: 确认游戏运行
```cmd
tasklist | findstr WorldOfTheThreeKingdoms
```
应该看到游戏进程。

### 步骤2: 运行窗口显示工具
```cmd
show_game_window.bat
```

### 步骤3: 检查结果
- 游戏窗口应该出现在屏幕中央
- 如果仍然不可见，尝试Alt+Tab

### 步骤4: 备用方案
如果窗口显示工具不起作用：
1. 结束游戏进程: `taskkill /f /im WorldOfTheThreeKingdoms.exe`
2. 重新启动: `setup_and_launch_game.bat`

2. **检查系统兼容性**: 尝试兼容模式运行
3. **检查防火墙**: 确保游戏未被阻止
4. **重启系统**: 有时系统重启可以解决显示问题
