# 军师谏言跳转问题修复报告

## 问题分析
根据调试日志显示：
```
[军师谏言] 开始显示招募界面
[军师谏言] 找到 10 名推荐武将
[军师谏言] 招募界面调用完成
```

调用成功但界面没有显示，说明 `ShowTabListInFrame` 方法被调用了，但由于某些原因没有生效。

## 可能原因
1. **界面状态冲突**：当前有其他对话框或界面阻止了新界面的显示
2. **UndoneWork状态问题**：游戏的工作栈状态不正确
3. **FrameFunction不匹配**：`PersonManualHire` 可能需要特定的上下文环境

## 修复方案
**文件**: `WorldOfTheThreeKingdoms/GameManager/AdvisorAdviceEventSystem.cs`

### 1. 强制清理界面状态
```csharp
// 确保关闭所有当前显示的对话框和界面
if (gameScreen.Plugins.tupianwenziPlugin.IsShowing)
{
    gameScreen.Plugins.tupianwenziPlugin.IsShowing = false;
    System.Diagnostics.Debug.WriteLine("[军师谏言] 关闭当前对话框");
}

if (gameScreen.Plugins.ConfirmationDialogPlugin.IsShowing)
{
    gameScreen.Plugins.ConfirmationDialogPlugin.IsShowing = false;
    System.Diagnostics.Debug.WriteLine("[军师谏言] 关闭确认对话框");
}

// 清理当前的UndoneWork状态
while (gameScreen.PeekUndoneWork().Kind != UndoneWorkKind.None)
{
    gameScreen.PopUndoneWork();
    System.Diagnostics.Debug.WriteLine("[军师谏言] 清理UndoneWork状态");
}
```

### 2. 改用Browse模式

// 尝试使用Browse模式显示，这样更稳定

## 修复策略

### 策略1：使用Browse模式
- **原因**：`FrameFunction.Browse` 是最通用和稳定的显示模式
- **优势**：不依赖特定的上下文环境，兼容性更好
- **后续**：可以在界面显示成功后再启用招募功能

### 策略2：强制清理状态
- **原因**：确保没有其他界面或状态阻止新界面显示
- **方法**：依次关闭所有可能的对话框和界面
- **验证**：通过调试日志确认每个步骤的执行情况

### 策略3：详细状态监控
- **目的**：准确定位问题所在
- **方法**：在关键步骤添加状态检查和日志输出
- **好处**：便于快速诊断和修复问题
