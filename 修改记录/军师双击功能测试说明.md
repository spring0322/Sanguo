# 军师双击空白地形功能测试说明

## 功能概述
双击游戏地图上的空白地形（没有建筑、部队、路径的普通地形）可以召唤军师管理菜单。

- `军师双击菜单系统集成.cs` - 集成代码示例

## 功能特点

### 双击检测
- 时间阈值：500毫秒内
- 距离阈值：5像素内
- 自动区分单击和双击

### 空白地形判断
- ✅ 排除有建筑的位置
- ✅ 排除有部队的位置  
- ✅ 排除有路径的位置
- ✅ 排除UI元素上的点击
- ✅ 支持所有地形类型（平原、山地、森林、水域等）

### 菜单功能
- 任命军师（如果没有军师）
- 重新任命军师（如果已有军师）
- 罢免军师
- 查看军师建议
- 查看军师信息

## 测试步骤

### 1. 基本功能测试
1. 启动游戏，进入主游戏界面
2. 在空白地形上双击鼠标左键
3. 应该看到军师管理菜单弹出
4. 菜单应显示当前势力的军师相关选项

### 2. 双击检测测试
1. 单击空白地形 - 不应弹出菜单
2. 双击空白地形 - 应弹出菜单
3. 双击间隔超过500ms - 不应弹出菜单
4. 双击位置相距超过5像素 - 不应弹出菜单

### 3. 空白地形判断测试
1. 双击建筑 - 不应弹出军师菜单（应显示建筑菜单）
2. 双击部队 - 不应弹出军师菜单（应显示部队菜单）
3. 双击UI面板 - 不应弹出军师菜单
4. 双击各种地形（山地、森林、水域等）- 都应弹出军师菜单

### 4. 菜单交互测试
1. 鼠标移动到菜单项上 - 应有高亮效果
2. 点击菜单项 - 应执行对应功能
3. 点击菜单外 - 应关闭菜单
4. 再次双击其他位置 - 应关闭当前菜单并在新位置显示

## 调试信息

程序会在控制台输出调试信息：
- `[MainGameScreen] 检测到双击空白地形: {位置}`
- `[军师菜单] 在空白地形双击: {位置}`
- `[MainGameScreen] 位置有建筑/部队/路径` - 当不是空白地形时
- `[MainGameScreen] 军师菜单已渲染` - 菜单渲染时

## 可能的问题和解决方案

### 1. 双击没有反应
**可能原因：**
- 菜单管理器未初始化
- 双击检测参数过严格
- 空白地形判断过严格

**解决方案：**
- 检查控制台是否有初始化信息
- 调整双击时间和距离阈值
- 检查是否正确判断为空白地形

### 2. 菜单不显示
**可能原因：**
- 渲染方法未调用
- 菜单位置超出屏幕
- 纹理资源缺失

**解决方案：**
- 检查Drawing方法是否调用了DrawAdvisorDoubleClickMenu
- 检查菜单边界计算
- 使用备用渲染方案

### 3. 菜单功能不工作
**可能原因：**
- ShowTabListInFrame方法调用失败
- 势力数据异常

**解决方案：**
- 检查Session.Current.Scenario.CurrentFaction是否有效
- 检查候选人列表是否为空
