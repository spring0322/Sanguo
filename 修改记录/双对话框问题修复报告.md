# 双对话框问题修复报告

## 问题分析

### 根本原因
项目中存在**两套不同的说服对话系统**同时运行：

1. **MainGameScreen.cs中的复杂系统**
   - `PerformAdvisorAnalysisAndRecommendation()`
   - `ShowAdvisorDissuasionDialogWithChoice()`
   - `ShowAdvisorDissuasionConfirmationDialog()`
   - 复杂的军师分析和UI对话框

2. **ScreenManager.cs中的简单系统**
   - `ShowSimpleAdvisorDialogue()`
   - `GetSimpleAdvisorDialogue()`
   - 简化的对话输出

### 冲突点
- `FrameFunction_Architecture_AfterGetConvinceTargetForAnalysis()` 调用复杂系统
- `FrameFunction_Architecture_AfterGetConvinceDestinationPerson()` 调用简单系统
- 两个系统可能同时被触发，导致出现两个对话框

## 修复方案

### 1. 删除复杂系统的调用
删除了以下内容：
- `FrameFunction_Architecture_AfterGetConvinceTargetForAnalysis()` 方法
- 对应的 `case FrameFunction.GetConvinceTargetForAnalysis` 处理
- 对 `Session.MainGame.mainGameScreen.PerformAdvisorAnalysisAndRecommendation()` 的调用

### 2. 保留简单系统
只保留 `FrameFunction_Architecture_AfterGetConvinceDestinationPerson()` 和相关的简单实现：

```csharp
private void FrameFunction_Architecture_AfterGetConvinceDestinationPerson()
{
    this.CurrentGameObjects = this.CurrentArchitecture.ConvinceDestinationPersonList.GetSelectedList();
    if ((this.CurrentGameObjects != null) && (this.CurrentGameObjects.Count == 1))
    {
        Person targetPerson = this.CurrentGameObjects[0] as Person;
        
        if (targetPerson != null && this.CurrentPersons != null && this.CurrentPersons.Count > 0)
        {
            ShowSimpleAdvisorDialogue(targetPerson);
        }
        else
        {
            // 原始逻辑：直接执行说服
            foreach (Person person in this.CurrentPersons)
            {
                person.GoForConvince(this.CurrentGameObjects[0] as Person);
            }
            Session.MainGame.mainGameScreen.PlayNormalSound("Content/Sound/Tactics/Outside");
        }
    }
}
```

### 3. 简化的军师对话
```csharp
private void ShowSimpleAdvisorDialogue(Person targetPerson)
{
    try
    {
        // 简单的成功率计算
        int successRate = 50; // 默认成功率
        
        // 获取对话内容
        string dialogue = GetSimpleAdvisorDialogue(targetPerson, successRate);
        
        // 输出到调试日志
        System.Diagnostics.Debug.WriteLine("[军师对话] " + dialogue);
        
        // 执行原始的说服逻辑
        foreach (Person person in this.CurrentPersons)
        {
            person.GoForConvince(targetPerson);
        }
        Session.MainGame.mainGameScreen.PlayNormalSound("Content/Sound/Tactics/Outside");
    }
    catch (Exception ex)
    {
        // 异常处理...
    }
}
```
