# 军师对话诊断方案

## 当前实现状态

### ✅ 已确认正确的部分
1. **流程连接** - ScreenManager → MainGameScreen.PerformAdvisorAnalysisAndRecommendation()
2. **参数修复** - SetGameObjectBranch中文内容在第3个参数位置
3. **对话框显示** - tupianwenziPlugin.IsShowing = true

### 🔍 可能的问题点

#### 1. 军师获取失败
**症状**: 没有任何对话显示
**原因**: 找不到合适的军师，直接跳转到人员选择
**检查方法**: 查看调试输出是否有"没有找到军师"

#### 2. 分析结果问题
**症状**: 有军师但没有对话
**原因**: 军师分析失败或结果异常
**检查方法**: 查看调试输出中的分析结果

#### 3. UI插件不可用
**症状**: 有分析但对话框不显示
**原因**: tupianwenziPlugin或ConfirmationDialogPlugin为null
**检查方法**: 查看调试输出中的插件状态

#### 4. 对话框被其他界面覆盖
**症状**: 对话框显示但看不到
**原因**: 其他UI界面在前面
**检查方法**: 检查是否有其他对话框同时显示

### 第一步：基础流程检查

### 第二步：问题定位
根据调试输出的中断点判断问题：

1. **如果在"进入FrameFunction"后中断** → 目标选择问题
2. **如果在"开始军师分析"后中断** → 军师获取问题
3. **如果在"分析结果"后中断** → 对话显示问题
4. **如果显示"对话框已显示"但看不到** → UI覆盖问题

### 第三步：具体修复
根据问题类型采用对应的修复方案。

## 备用方案

如果复杂系统还是有问题，可以采用简化方案：

### 方案A：简化军师对话
直接在ScreenManager中实现简单的军师对话，不依赖复杂系统：

```csharp
private void ShowSimpleAdvisorDialog(Person targetPerson)
{
    // 获取军师
    var advisor = this.CurrentArchitecture.BelongedFaction.Leader;
    
    // 简单对话内容
    string message = $"主公，关于说服{targetPerson.Name}一事，您意下如何？";
    
    // 显示确认对话框
    Session.MainGame.mainGameScreen.Plugins.ConfirmationDialogPlugin.SetSimpleTextDialog(
        Session.MainGame.mainGameScreen.Plugins.SimpleTextDialogPlugin);
    
    // 设置回调
    Session.MainGame.mainGameScreen.Plugins.ConfirmationDialogPlugin.AddYesFunction(
        new GameDelegates.VoidFunction(() => {
            // 执行说服
            ExecuteConvince(targetPerson);
        }));
    
    Session.MainGame.mainGameScreen.Plugins.ConfirmationDialogPlugin.AddNoFunction(
        new GameDelegates.VoidFunction(() => {
            // 取消操作
        }));
    
    // 显示对话
    Session.MainGame.mainGameScreen.Plugins.SimpleTextDialogPlugin.SetBranch("AdvisorConvince");
    Session.MainGame.mainGameScreen.Plugins.ConfirmationDialogPlugin.SetPosition(ShowPosition.Center);
    Session.MainGame.mainGameScreen.Plugins.ConfirmationDialogPlugin.IsShowing = true;
}
```

### 方案B：配置文件方案
启用之前创建的XML配置文件和AdvisorConvinceDialogueManager。
