## 🧮 核心算法

### CalculateVictimScore - 攻击目标评分
```csharp
private static float CalculateVictimScore(Faction me, Faction target)
{
    // 1. 距离衰减 (距离越远，分越低)
    float dist = CalculateDistance(me, target);
    if (dist > 5) return 0; // 太远了不打

    // 2. 实力对比 (欺负弱小)
    float ratio = me.TotalMilitaryPower / (target.TotalMilitaryPower + 1f);

    // 3. 基础分 - 目标财富除以距离
    float score = target.CityWealth / dist;

    // 4. 霸凌逻辑
    if (ratio > 3.0f) {
        score *= 5.0f; // 极度诱人，简直是送肉
    } else if (ratio < 0.8f) {
        score = -100f; // 打不过，绝对不打
    }

    // 5. 机会主义 (军师眼里的破绽)
    if (target.IsFightingOthers) {
        score += 500f; // 趁火打劫权重极大
    }

    return score;
}
```

## 🔍 评分因素详解

### 1. 距离衰减系统
- **检测半径**: 5格以内才考虑攻击
- **距离计算**: 使用曼哈顿距离（城池间最短距离）
- **衰减效果**: 距离越远，基础分越低

### 2. 实力对比分析
- **霸凌逻辑**: 实力比>3:1时，评分×5（"送肉"）
- **自保机制**: 实力比<0.8:1时，评分-100（"打不过"）
- **合理交战**: 0.8-3之间正常评分

### 3. 财富诱惑计算
- **城市财富**: 资金+粮食+城池数量加成
- **距离修正**: 财富/距离 = 性价比
- **港口加成**: 港口城市+100分
- **要塞加成**: 高耐久城池+50分

### 4. 机会主义检测
- **交战状态**: 目标正在打仗+500分（趁火打劫）
- **敌军逼近**: 有敌军在目标城池附近
- **部队在外**: 目标有部队在行军状态

### 5. 战略价值评估
- **地理位置**: 港口、要塞、人口密集区
- **外交关系**: 仇敌+200分，盟友-500分
- **势力威胁**: 大势力消灭价值更高
