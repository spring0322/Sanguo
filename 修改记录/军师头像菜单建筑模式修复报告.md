# 军师头像菜单系统 - 建筑模式修复报告

## 问题分析

用户反馈军师头像菜单仍然无法稳定保持，建议参考建筑菜单的设定。经过分析发现：

### 建筑菜单的工作模式
1. **鼠标按下时**：只记录点击状态，不立即显示菜单
2. **鼠标松开时**：检查条件并显示菜单
3. **条件检查**：`!this.Plugins.ContextMenuPlugin.IsShowing && Session.Current.Scenario.IsPlayerControlling()`
4. **无延迟机制**：直接在鼠标松开时显示菜单，不使用帧延迟

### 军师头像菜单的问题
1. **延迟显示机制复杂**：使用帧延迟增加了复杂性
2. **事件处理时机错误**：在鼠标按下时就尝试显示菜单
3. **缺乏条件检查**：没有检查菜单是否已经显示

## 修复方案：采用建筑菜单模式

### 1. 修改鼠标事件处理

**鼠标按下时**：只记录点击状态
```csharp
private void HandleMouseLeftDownForAdvisorPortrait(Point position)
{
    try
    {
        // 只在正常游戏状态下处理头像点击
        if (base.UndoneWorks.Peek().Kind == UndoneWorkKind.None)
        {
            // 检查是否点击了头像区域
            Rectangle portraitRect = GetAdvisorPortraitRect();
            if (StaticMethods.PointInRectangle(position, portraitRect))
            {
                // 设置标志，表示点击了军师头像，在鼠标松开时处理
                _advisorPortraitClicked = true;
                System.Diagnostics.Debug.WriteLine("[MainGameScreen] 军师头像被点击，等待鼠标松开处理");
            }
        }
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"[HandleMouseLeftDownForAdvisorPortrait] 异常: {ex.Message}");
    }
}
```

### 2. 实现菜单显示逻辑

**按照建筑菜单的模式**：
```csharp
private void HandleAdvisorPortraitMenuDisplay()
{
    try
    {
        System.Diagnostics.Debug.WriteLine("[MainGameScreen] 处理军师头像菜单显示");
        
        // 按照建筑菜单的模式：只有在菜单没有显示时才显示菜单
        if (!this.Plugins.ContextMenuPlugin.IsShowing && Session.Current.Scenario.IsPlayerControlling())
        {
            this.Plugins.ContextMenuPlugin.IsShowing = true;
            this.Plugins.ContextMenuPlugin.SetCurrentGameObject(this);
            this.Plugins.ContextMenuPlugin.SetMenuKindByName("AdvisorPortrait");
            this.Plugins.ContextMenuPlugin.Prepare(base.MousePosition.X, base.MousePosition.Y, base.viewportSize);
            
            // 设置标识，用于区分菜单类型
            this.bianduiLiebiaoBiaoji = "AdvisorPortrait";
            
            System.Diagnostics.Debug.WriteLine($"[MainGameScreen] 军师头像菜单显示完成，IsShowing: {this.Plugins.ContextMenuPlugin.IsShowing}");
        }
        else
        {
            System.Diagnostics.Debug.WriteLine($"[MainGameScreen] 菜单已显示或玩家无法控制，跳过显示");
        }
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"[HandleAdvisorPortraitMenuDisplay] 异常: {ex.Message}");
    }
}
```

## 关键改进

### 1. 事件处理时机
- **之前**：鼠标按下时立即显示菜单 → 导致事件冲突
- **现在**：鼠标松开时显示菜单 → 避免事件冲突

### 2. 条件检查
- **之前**：缺乏菜单状态检查
- **现在**：`!this.Plugins.ContextMenuPlugin.IsShowing` → 防止重复显示

### 3. 代码复杂度
- **之前**：复杂的延迟机制和帧处理
- **现在**：简单的标志位和直接处理

### 4. 一致性
- **之前**：与游戏其他菜单处理方式不一致
- **现在**：完全按照建筑菜单的模式，保持一致性
