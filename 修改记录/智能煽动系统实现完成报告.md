- 分析最佳执行人员和预测成功率
- 基于执行人员能力和目标建筑特性计算成功率
- 根据分析结果决定显示支持还是劝阻对话

#### 智能对话系统
- **成功率≥67%**: 显示支持对话，自动勾选推荐人员
- **成功率34-66%**: 显示支持对话，让玩家选择是否采纳建议
- **成功率≤33%**: 显示劝阻对话，玩家可选择坚持或放弃

#### 军师支持对话


#### 军师劝阻对话
```

```

#### 成功率描述模板
- **0%**: "此建筑民心稳固，煽动行动一定不能成功，建议换个目标或等待时机。"
- **1-33%**: "此建筑民心较稳，煽动成功的机会微乎其微。"
- **34-66%**: "此建筑民心一般，煽动行动有一定的成功几率。"
- **67-99%**: "此建筑民心不稳，煽动成功的概率很高。"
- **100%**: "此建筑民心涣散，煽动行动万无一失！"

#### 成功率计算算法
```csharp
private int CalculateInstigateSuccessRate(Person executor, Architecture target)
{
    // 基于执行人员的煽动能力和目标建筑的民心状况
    int executorAbility = executor.InstigateAbility;
    int targetResistance = target.Domination * 6; // 煽动比破坏稍容易
    
    if (executorAbility <= 120) return 0; // 能力太低
    
    double successRate = (double)executorAbility / (executorAbility + targetResistance) * 100;
    return Math.Max(0, Math.Min(100, (int)successRate));
}
```

## 完整的用户流程

### 智能煽动流程
1. **入口**: 右键建筑 → 选择"煽动"
2. **目标选择**: 显示所有可煽动的目标建筑列表
3. **选择目标**: 玩家选择要煽动的具体建筑
4. **军师分析**: 系统分析最佳执行人员和成功率
5. **智能对话**: 根据成功率显示支持或劝阻对话
6. **用户决策**: 玩家选择是否采纳建议或坚持执行
7. **人员选择**: 显示执行人员选择界面（可能预选推荐人员）
8. **执行煽动**: 选择人员后直接执行煽动任务

### 与原系统的区别
| 原煽动系统 | 智能煽动系统 |
|-----------|-------------|
| 先选人员，后选目标 | 先选目标，后选人员 |
| 无军师分析 | 完整的军师分析和建议 |
| 无智能推荐 | 自动推荐最佳执行人员 |
| 无成功率预测 | 基于能力的成功率计算 |
| 无对话交互 | 丰富的军师对话系统 |
