### Faction.cs - 恢复正确的候选人条件
```csharp
public PersonList AdvisorCandicate
{
    get
    {
        PersonList result = new PersonList();
        foreach (Person p in this.Persons)
        {
            if (p != this.Leader && p != this.Advisor && p.Available && p.Alive && 
                p.BelongedCaptive == null && p.LocationTroop == null && p.Intelligence >= 70)
            {
                result.Add(p);
            }
        }
        return result;
    }
}
```

### StrategistUI.cs - 增强的点击处理
```csharp
private void OnAdvisorButtonClicked()
{
    var faction = Session.Current?.Scenario?.CurrentPlayer;
    
    // 检查是否可以任命军师
    if (!faction.AppointAdvisorAvail())
    {
        // 详细诊断原因
        if (faction.Leader == null) // 没有君主
        if (faction.Leader.BelongedCaptive != null) // 君主被俘
        if (!Session.Current.Scenario.IsPlayer(faction)) // 不是玩家势力
        if (faction.AdvisorCandicate.Count == 0) // 没有候选人
        return;
    }
    
    // 调用游戏原生任命界面
    mainGameScreen.ShowTabListInFrame(...);
}
```

## 📊 候选人条件详解

军师候选人必须同时满足以下所有条件：

1. **不是君主**: `p != this.Leader`
2. **不是当前军师**: `p != this.Advisor`  
3. **人物可用**: `p.Available == true`
4. **人物存活**: `p.Alive == true`
5. **未被俘虏**: `p.BelongedCaptive == null`
6. **不在部队中**: `p.LocationTroop == null`
7. **智力足够**: `p.Intelligence >= 70` ⭐
