**修复后的正确代码**:

**关键改进**:

### 2. StrategistUI系统修复 ✅

**问题根源**: StrategistUI的绘制代码被注释掉了

**修复内容**:
```csharp
// 修复前：绘制代码被注释
/*
if (_strategistUI != null && Session.Current?.Scenario != null)
{
    _strategistUI.Draw(Session.MainGame.SpriteBatch);
}
*/

// 修复后：启用绘制并添加异常保护
if (_strategistUI != null && Session.Current?.Scenario != null)
{
    try
    {
        _strategistUI.Draw(Session.MainGame.SpriteBatch);
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"[MainGameScreen] StrategistUI绘制异常: {ex.Message}");
    }
}
```

**关键改进**:
- 启用了StrategistUI的绘制功能
- 添加了异常保护，防止绘制错误导致游戏崩溃
- 这可能解决了坐标(1091, 472)附近的绘制区域无效错误
