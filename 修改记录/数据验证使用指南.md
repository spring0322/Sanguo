# 数据验证使用指南

## 🎯 验证功能概述

整合了你的 `ValidateData` 方法，并增强了以下功能：
- **自动验证**: 在 `LoadData` 时自动验证
- **独立验证**: 可以单独验证数据而不加载
- **详细报告**: 提供错误和警告的详细信息
- **数据统计**: 提供完整的数据统计信息

## 🚀 使用方法

### **方法1: 自动验证（推荐）**

```csharp
// 正常加载数据，会自动验证
var loader = new IntegratedSkillDataLoader();

try
{
    loader.LoadData(jsonContent); // 自动调用ValidateData
    Console.WriteLine("数据加载和验证成功！");
}
catch (Exception ex)
{
    Console.WriteLine($"验证失败: {ex.Message}");
    // 处理验证错误
}
```

### **方法2: 独立验证**

```csharp
// 只验证数据，不进行加载
var loader = new IntegratedSkillDataLoader();

// 先手动加载基础数据
// ... 加载Influences和Skills ...

// 然后验证
var result = loader.ValidateDataOnly();

if (result.IsValid)
{
    Console.WriteLine("验证通过，可以安全使用数据");
}
else
{
    Console.WriteLine($"发现 {result.ErrorCount} 个错误");
    result.PrintSummary(); // 显示详细错误信息
}
```

## 🔍 验证内容

### **严重错误（会阻止加载）**
- ❌ 技能引用不存在的效果ID
- ❌ 技能包含无效的效果ID格式
- ❌ 技能缺少名称
- ❌ 效果缺少Kind信息

### **警告（不会阻止加载）**
- ⚠️ 技能没有效果字符串
- ⚠️ 效果缺少名称

## 🛠️ 自定义验证规则

### **添加新的验证规则**

```csharp
// 在ValidateData方法中添加自定义验证
public void ValidateData()
{
    // ... 现有验证逻辑 ...
    
    // 自定义验证：检查技能描述
    foreach (var skill in AllSkills)
    {
        if (string.IsNullOrEmpty(skill.Description))
        {
            Console.WriteLine($"[警告] 技能 {skill.Name}(ID:{skill.ID}) 缺少描述");
            warningCount++;
        }
        
        // 自定义验证：检查技能名称长度
        if (skill.Name != null && skill.Name.Length > 20)
        {
            Console.WriteLine($"[警告] 技能 {skill.Name}(ID:{skill.ID}) 名称过长");
            warningCount++;
        }
    }
    
    // 自定义验证：检查效果参数
    foreach (var influence in AllInfluences.Values)
    {
        if (!string.IsNullOrEmpty(influence.Parameter))
        {
            if (!float.TryParse(influence.Parameter, out _))
            {
                Debug.LogError($"[严重错误] 效果 {influence.Name}(ID:{influence.ID}) 参数格式错误: {influence.Parameter}");
                errorCount++;
            }
        }
    }
}
```

```csharp
private void ValidateSkillBalance()
{

    {
        float totalValue = skill.AIProfile.GetTotalValue();
        
        // 检查技能是否过于强力
        if (totalValue > 200f)
        {
            Console.WriteLine($"[警告] 技能 {skill.Name} 可能过于强力 (价值: {totalValue:F1})");
        }
        
        // 检查技能是否过于弱小
        if (totalValue < 10f && skill.LinkedInfluences.Any())
        {
            Console.WriteLine($"[警告] 技能 {skill.Name} 可能过于弱小 (价值: {totalValue:F1})");
        }
    }
}
```

### **验证性能优化**

```csharp
// 对于大量数据，可以使用并行验证
public void ValidateDataParallel()
{
    var errors = new ConcurrentBag<string>();
    var warnings = new ConcurrentBag<string>();
    
    Parallel.ForEach(AllSkills, skill =>
    {
        // 并行验证每个技能
        ValidateSingleSkill(skill, errors, warnings);
    });
    
    // 汇总结果
    Console.WriteLine($"并行验证完成: {errors.Count} 个错误, {warnings.Count} 个警告");
}
```

### **缓存验证结果**

```csharp
// 缓存验证结果，避免重复验证
private static Dictionary<string, ValidationResult> _validationCache = 
    new Dictionary<string, ValidationResult>();

public ValidationResult ValidateWithCache(string dataHash)
{
    if (_validationCache.TryGetValue(dataHash, out var cachedResult))
    {
        Console.WriteLine("使用缓存的验证结果");
        return cachedResult;
    }
    
    var result = ValidateDataOnly();
    _validationCache[dataHash] = result;
    return result;
}
```
