# 军师对话框完整修复报告

## 问题总结
1. **显示问题**: 只显示简单确认框，没有军师头像和对话内容
2. **逻辑错误**: 选择逻辑不正确
3. **程序卡死**: 点击"是"后程序卡住

## 最终解决方案

### 1. 参考军师任命对话的实现
通过分析`任命军师完整代码展示.cs`中的成功实现，采用了正确的对话显示方式：

```csharp
// 1. 设置军师对话内容
advisor.TextResultString = advisorMessage;

// 2. 设置确认对话框回调
this.Plugins.tupianwenziPlugin.SetConfirmationDialog(
    this.Plugins.ConfirmationDialogPlugin,
    yesCallback,
    noCallback
);

// 3. 设置对话框位置
this.Plugins.ConfirmationDialogPlugin.SetPosition(ShowPosition.Center);

// 4. 显示军师头像和对话
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    advisor,
    advisor,
    TextMessageKind.InformationSuccess, // 或 InformationFailure
    "AdvisorSupport" // 或 "AdvisorDissuasion"
);

// 5. 设置位置并显示
this.Plugins.tupianwenziPlugin.SetPosition(ShowPosition.Bottom, this);
this.Plugins.tupianwenziPlugin.IsShowing = true;
```

### 2. 修复程序卡死问题
**根本原因**: `ShowExecutorSelectionWithRecommendation`方法中的空指针异常

**修复方案**: 添加空值检查和异常处理
```csharp
private void ShowExecutorSelectionWithRecommendation(Architecture sourceArchitecture, Person recommendedPerson)
{
    try
    {
        if (recommendedPerson != null)
        {
            // 正常处理推荐人员
            recommendedPerson.Selected = true;
            // ...
        }
        else
        {
            // 推荐人员为空时的降级处理
            ShowExecutorSelectionForConvince(sourceArchitecture);
        }
    }
    catch (Exception ex)
    {
        // 异常处理，防止程序卡死
        ShowExecutorSelectionForConvince(sourceArchitecture);
    }
}
```

### 3. 正确的选择逻辑
- **军师支持对话**: "是"=采纳建议，"否"=自己选择
- **军师劝阻对话**: "是"=坚持执行，"否"=听从劝告

## 技术实现要点

### 1. 对话显示流程
1. 获取军师对象（Advisor → 建筑军师 → 君主）
2. 构建中文对话内容并设置到`advisor.TextResultString`
3. 设置确认对话框的回调函数
4. 调用`tupianwenziPlugin.SetGameObjectBranch`显示军师头像
5. 设置位置并显示对话框

### 2. 异常处理机制
- 每个回调函数都有try-catch保护
- 空值检查防止空指针异常
- 降级处理确保功能可用

### 3. 对话内容
#### 军师支持对话
```
主公，关于说服{目标人物}一事：

经过分析，我认为此次行动成功率较高（约{成功率}%）。

推荐派遣{推荐人选}前往执行。

是否采纳军师建议？
```

#### 军师劝阻对话
```
主公，关于说服{目标人物}一事：

经过分析，此次行动风险较高，成功率仅约{成功率}%。

即使派遣{推荐人选}前往，成功把握也不大。

臣建议主公三思而后行，此时贸然行动恐怕得不偿失。

是否坚持执行？
```
