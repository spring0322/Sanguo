# 军师对话系统修复总结

## 问题描述
军师任命及罢免对话挤在一个对话框里面，需要实现两个人分别说话的轮流对话效果。

## 问题分析

### 1. 事件系统对话机制研究
通过深入研究事件系统的对话实现，发现了关键机制：
- 事件系统使用 `PersonDialog` 列表存储多个对话
- 在 `foreach` 循环中连续调用 `SetGameObjectBranch()` 将对话加入队列
- `tupianwenziPlugin` 内部使用 `DisplayQueue` 管理对话队列
- 关键：**先加入所有对话，然后设置回调，最后启动显示**

### 2. 关键发现
事件系统的处理顺序：
```csharp
// 1. 先将所有对话加入队列
foreach (PersonDialog dialog in e.matchedDialog)
{
    this.Plugins.tupianwenziPlugin.SetGameObjectBranch(dialog.SpeakingPerson, null, dialog.Text, e.Image, e.Sound, e.TryToShowString);
}

// 2. 然后设置关闭回调
this.Plugins.tupianwenziPlugin.SetCloseFunction(new GameDelegates.VoidFunction(Session.Current.Scenario.ApplyEvents));

// 3. 最后启动显示
(this.Plugins.tupianwenziPlugin as tupianwenziPlugin.tupianwenziPlugin).tupianwenzi.SetIsShowing(this, true);
```

## 解决方案

### 1. 统一配置文件
- 使用 `Content/Data/Plugins/AdvisorDialogueTemplate.xml` 作为唯一的对话配置文件
- 废弃之前的三个独立配置文件

### 2. 正确的对话队列实现

#### 关键修复点
1. **正确的调用顺序**：先加入所有对话，再设置回调，最后启动显示
2. **使用SetIsShowing方法**：使用 `tupianwenzi.SetIsShowing(screen, true)` 而不是 `IsShowing = true`
3. **检查DialogShowTime**：确保 `Setting.Current.GlobalVariables.DialogShowTime > 0`

#### 实现代码
```csharp
// 设置对话位置
mainScreen.Plugins.tupianwenziPlugin.SetPosition(ShowPosition.Bottom, mainScreen);

// 第一个对话：君主说话（加入队列）
mainScreen.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    leader, leader, dialogue.LeaderText, imageName, "", "");

// 第二个对话：军师回应（加入队列）
mainScreen.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    candidate, candidate, dialogue.AdvisorText, imageName, "", "");

// 在所有对话加入队列后，设置关闭回调和开始显示
if (Setting.Current.GlobalVariables.DialogShowTime > 0)
{
    // 设置关闭回调
    mainScreen.Plugins.tupianwenziPlugin.SetCloseFunction(callback);
    
    // 开始显示对话
    (mainScreen.Plugins.tupianwenziPlugin as tupianwenziPlugin.tupianwenziPlugin).tupianwenzi.SetIsShowing(mainScreen, true);
}
```

## 对话流程

### 任命成功流程
1. 君主对话加入队列
2. 军师回应加入队列
3. 设置成功回调（记录事件）
4. 启动显示，系统自动轮流显示
5. 对话结束后执行回调

### 任命拒绝流程
1. 君主邀请加入队列
2. 军师拒绝加入队列
3. 设置拒绝回调（不记录事件）
4. 启动显示，系统自动轮流显示
5. 对话结束后执行回调

### 罢免流程
1. 君主通知加入队列
2. 军师接受加入队列
3. 设置罢免回调（记录事件）
4. 启动显示，系统自动轮流显示
5. 对话结束后执行回调
