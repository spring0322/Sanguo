# 屏幕显示问题修复报告

## 问题描述
- **症状1**: 屏幕下边三分之一显示为黑屏
- **症状2**: 游戏画面缩在左上角
- **症状3**: 引发 `System.ArgumentNullException` 和 `System.IndexOutOfRangeException` 异常

## 根本原因分析

### 1. 视口计算错误 (主要原因)
**位置**: `MainGameScreen.cs` - `UpdateViewport()` 方法
- **问题**: 直接访问 `this.Plugins.ToolBarPlugin.Height` 时可能出现空引用
- **后果**: 导致视口高度计算错误，屏幕显示区域异常

### 2. 屏幕边界计算异常
**位置**: `MainGameScreen.cs` - `ResetScreenEdge()` 方法
- **问题**: 除零异常 - `TileWidth` 或 `TileHeight` 可能为0
- **后果**: 导致画面缩在左上角，显示区域计算错误

### 3. 数组越界异常
**位置**: `MainMapLayer.cs` - `ResetDisplayingTiles()` 方法
- **问题**: 循环边界超出数组范围，访问 `Tiles[i, j]` 时越界
- **后果**: 抛出 `IndexOutOfRangeException`，渲染中断

### 4. 分辨率解析异常
**位置**: `Session.cs` - `ChangeDisplay()` 方法
- **问题**: 分辨率字符串解析失败，除零异常
- **后果**: 缩放矩阵计算错误，影响整体显示

## 修复方案

### 1. 修复视口计算 (`MainGameScreen.cs`)
```csharp
// 添加空值检查和异常处理
int toolBarHeight = 0;
try
{
    if (this.Plugins?.ToolBarPlugin != null)
    {
        toolBarHeight = this.Plugins.ToolBarPlugin.Height;
    }
}
catch (Exception ex)
{
    System.Diagnostics.Debug.WriteLine($"[UpdateViewport] ToolBarPlugin异常: {ex.Message}");
    toolBarHeight = 0;
}

// 确保视口尺寸有效
this.viewportSize.Y = Math.Max(100, viewportHeight - toolBarHeight);
```

### 2. 修复屏幕边界计算 (`MainGameScreen.cs`)
```csharp
// 防止除零异常
if (tileWidth <= 0 || tileHeight <= 0)
{
    tileWidth = Math.Max(tileWidth, 32);  // 默认瓦片宽度
    tileHeight = Math.Max(tileHeight, 32); // 默认瓦片高度
}

// 确保边界值在合理范围内
this.TopLeftPosition.X = Math.Max(0, Math.Min(this.TopLeftPosition.X, mapWidth - 1));
this.TopLeftPosition.Y = Math.Max(0, Math.Min(this.TopLeftPosition.Y, mapHeight - 1));
```

### 3. 修复数组越界 (`MainMapLayer.cs`)
```csharp
// 确保循环边界在有效范围内
int startX = Math.Max(0, screen.TopLeftPosition.X);
int endX = Math.Min(Session.Current.Scenario.ScenarioMap.MapDimensions.X - 1, screen.BottomRightPosition.X);

// 双重检查边界，防止数组越界
if (i >= 0 && i < Session.Current.Scenario.ScenarioMap.MapDimensions.X && 
    j >= 0 && j < Session.Current.Scenario.ScenarioMap.MapDimensions.Y &&
    i < this.Tiles.GetLength(0) && j < this.Tiles.GetLength(1))
{
    this.DisplayingTiles.Add(this.Tiles[i, j]);
}
```

### 4. 修复分辨率解析 (`Session.cs`)
```csharp
// 添加分辨率解析的异常处理
try
{
    string[] resolutionParts = Session.Resolution.Split('*');
    if (resolutionParts.Length >= 2)
    {
        width = int.Parse(resolutionParts[0]);
        height = int.Parse(resolutionParts[1]);
    }
    else
    {
        // 使用默认分辨率
        width = 1024;
        height = 768;
    }
}
catch (Exception ex)
{
    // 解析失败时使用默认分辨率
    width = 1024;
    height = 768;
}

// 防止除零异常
float resolutionX = Math.Max(Session.ResolutionX, 1);
float resolutionY = Math.Max(Session.ResolutionY, 1);
```

## 修复效果

### 解决的问题
1. ✅ **消除黑屏**: 正确计算视口高度，确保全屏显示
2. ✅ **修复画面位置**: 屏幕边界计算正确，画面不再缩在左上角
3. ✅ **消除异常**: 添加边界检查和异常处理，防止崩溃
4. ✅ **提高稳定性**: 防御性编程，增强代码健壮性

### 技术改进
- **空值检查**: 所有可能为空的对象都添加了检查
- **边界验证**: 数组访问前都进行边界验证
- **异常处理**: 关键计算都包含在try-catch块中
- **默认值**: 为异常情况提供合理的默认值
- **调试日志**: 添加详细的调试信息便于问题排查
