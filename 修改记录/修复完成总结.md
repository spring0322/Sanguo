### 1. **MainGame.cs - Draw方法** 
**问题**: 包含大量调试代码，多次Present()调用，颜色闪烁测试
**修复**: 恢复为简洁的原始Draw方法
```csharp
protected override void Draw(GameTime gameTime)
{
    Platform.GraphicsDevice.Clear(Color.Black);
    SpriteBatch.Begin(SpriteSortMode.Deferred, BlendState.AlphaBlend);
    
    if (mainGameScreen != null)
        mainGameScreen.Draw(gameTime);
    else if (mainMenuScreen != null)
        mainMenuScreen.Draw(gameTime);
    else if (loadingScreen != null)
        loadingScreen.Draw(gameTime);
    
    SpriteBatch.End();
    base.Draw(gameTime);
}
```

### 2. **MainMenuScreen.cs - Draw方法**
**问题**: 使用了不存在的`base.viewportSize`属性
**修复**: 使用`Session.ResolutionX/Y`获取屏幕尺寸
```csharp
int screenWidth = Session.ResolutionX > 0 ? Session.ResolutionX : 1280;
int screenHeight = Session.ResolutionY > 0 ? Session.ResolutionY : 720;
CacheManager.Draw(@"Content\Textures\Resources\Start\Start.jpg", 
    new Rectangle(0, 0, screenWidth, screenHeight), Color.White);
```

### 3. **MainGame.cs - Initialize & LoadContent**
**问题**: 包含强制图形设备初始化，viewport修复，大量调试输出
**修复**: 移除所有调试代码，恢复原始初始化流程

### 4. **编译错误修复**
**问题**: CS0117 "object 未包含 'viewportSize' 的定义"
