# 成功率低分两次对话功能报告

## 新增功能

### 功能描述
当军师预测成功率很低（0%或1-33%）时，将对话分为两次展示：
1. **第一次对话**：显示成功率判断
2. **第二次对话**：显示"是否继续？"问句

### 触发条件
- **成功率 ≤ 33%**（包括0%和1-33%的情况）

## 用户体验流程

### 成功率为0%的流程
1. **第一次对话** → "主公，说服{目标}一事，一定不能成功，建议换个人或者时机。"
2. **用户点击确定** → 关闭第一次对话
3. **第二次对话** → "是否继续？"
4. **用户选择**：
   - **点击"是"** → 进入执行人员选择界面
   - **点击"否"** → 直接结束流程

### 成功率为1-33%的流程
1. **第一次对话** → "主公，说服{目标}一事，成功机会微乎其微。"
2. **用户点击确定** → 关闭第一次对话
3. **第二次对话** → "是否继续？"
4. **用户选择**：
   - **点击"是"** → 进入执行人员选择界面
   - **点击"否"** → 直接结束流程

### 新增方法

#### 1. ShowLowSuccessRateDissuasionDialog
- **功能**：显示第一次对话（成功率判断）
- **特点**：只有确定按钮，点击后显示第二次对话

#### 2. ShowContinueQuestionDialog
- **功能**：显示第二次对话（"是否继续？"）
- **特点**：有"是/否"按钮，提供最终选择

#### 3. NeedsContinueQuestion
- **功能**：判断是否需要显示"是否继续？"问句
- **条件**：成功率 ≤ 33%

## 完整的成功率分级处理

### 更新后的分级处理
1. **0%**: 分两次对话 → "一定不能成功" → "是否继续？"
2. **1-33%**: 分两次对话 → "成功机会微乎其微" → "是否继续？"
3. **34-66%**: 单次对话 → "有一定的成功几率" → 需要用户选择执行人员
4. **67-99%**: 单次对话 → "成功概率很高" → 自动执行
5. **100%**: 单次对话 → "万无一失" → 自动执行

### 对话框数量对比
- **成功率低（0-33%）**: **2个对话框**
- **成功率中等（34-66%）**: 1个对话框
- **成功率高（67%以上）**: 1个对话框

## 用户体验优化

### ✅ 信息分层展示
1. **避免信息过载** - 将判断和问句分开显示
2. **逐步引导** - 先让用户了解情况，再做决定
3. **清晰的选择点** - "是否继续？"提供明确的决策点

### ✅ 符合用户心理
1. **缓冲效果** - 给用户时间消化军师的判断
2. **二次确认** - 成功率低时提供额外的思考机会
3. **保持选择权** - 即使成功率低，用户仍可选择继续

### ✅ 界面友好性
1. **避免文字拥挤** - 分两次显示避免单个对话框内容过多
2. **操作简单** - 每次只需要一个简单的选择
3. **流程清晰** - 用户能清楚地知道当前处于哪个步骤
