# 军师策略系统事件对话框重构完成报告

## 🎯 任务概述

根据用户反馈，军师策略建议系统存在以下问题：
1. **绘制区域无效错误**：新出现的坐标 {X:1067 Y:576 Width:0 Height:0} 和 {X:1067 Y:603 Width:0 Height:0} 错误

3. **需要改用事件对话框**：要求使用 tupianwenziPlugin 事件对话框形式，而不是当前的 xianshishijiantupian 方法

## ✅ 完成的修复

### 1. 重构军师建议显示系统

**修改文件**：`WorldOfTheThreeKingdoms/GameScreens/MainGameScreen.cs`

**核心改进**：
- ✅ **替换显示方法**：从 `xianshishijiantupian` 改为 `tupianwenziPlugin.SetGameObjectBranch`
- ✅ **事件对话框流程**：实现完整的事件对话框 → 用户确认 → 人员选择流程
- ✅ **回调机制**：使用 `SetCloseFunction` 实现对话框关闭后的后续处理
- ✅ **异常处理**：添加完整的 try-catch 错误处理，确保系统稳定性

**新的流程**：
```
点击策略 → 事件对话框显示军师建议 → 用户点击确认 → 
根据成功率决定：
- 高成功率(≥60%)：直接进入人员选择并预选推荐人员
- 低成功率(<60%)：显示风险确认对话框 → 用户选择是否继续
```

## 🎮 用户体验流程

### 高成功率策略（≥60%）
1. 用户点击策略（如搜索）
2. 显示军师建议对话框："XXX机敏过人，搜索之事交予此人最为合适。预计成功率85%。"
3. 用户点击确认
4. 直接进入人员选择界面，推荐人员已被预选
5. 用户可以确认使用推荐人员，或选择其他人员

### 低成功率策略（<60%）
1. 用户点击策略（如暗杀）
2. 显示军师建议对话框："此计凶险异常，XXX虽然勇武，成功率也只有35%。主公三思！"
3. 用户点击确认
4. 显示风险确认对话框："军师认为此策略成功率仅有35%，是否仍要执行？"
5. 用户选择：
   - 选择"是"：进入人员选择界面，无预选人员
   - 选择"否"：取消操作，返回游戏
