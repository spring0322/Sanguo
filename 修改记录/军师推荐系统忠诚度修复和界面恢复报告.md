# 军师推荐系统忠诚度修复和界面恢复报告

## 问题分析

根据最新的测试日志，发现了忠诚度设置的根本问题：

### 忠诚度问题详细分析

**测试日志显示**：
```
[招募操作] 计算出的目标忠诚度: 88
[招募操作] MoveToArchitecture后 - PersonalLoyalty: 4, Loyalty: 0, TempLoyaltyChange: 0
[招募操作] 忠诚度调整计算:
  当前基础忠诚度: 0
  目标忠诚度: 88
  需要的临时调整: 88
  设置TempLoyaltyChange: 88
[招募操作] 最终忠诚度验证: 0
```

**问题根源**：
- Person.Loyalty属性的计算中，基础值可能是负数
- 由于`v = Math.Max(0, v)`的存在，负值被截断为0
- 即使设置了TempLoyaltyChange，如果基础值过低，最终结果仍可能为0

## 修复方案

### 1. 忠诚度设置算法优化

**修改文件**：`WorldOfTheThreeKingdoms/GameManager/AdvisorAdviceEventSystem.cs`

**新的忠诚度设置逻辑**：
```csharp
// 直接设置足够大的TempLoyaltyChange来确保达到目标忠诚度
// 由于Person.Loyalty的计算很复杂，可能存在负基础值被Math.Max(0,v)截断的情况
// 我们直接设置一个足够大的值来确保最终结果为正数

person.TempLoyaltyChange = calculatedLoyalty + 200; // 额外加200确保覆盖负基础值

// 验证最终忠诚度，如果还是不够，继续增加
int attempts = 0;
while (finalLoyalty < calculatedLoyalty && attempts < 5)
{
    attempts++;
    person.TempLoyaltyChange += 100; // 每次增加100
    finalLoyalty = person.Loyalty;
}
```

**优势**：
- 不再依赖复杂的反向计算
- 直接设置足够大的值确保覆盖任何负基础值
- 循环验证和调整，确保达到目标忠诚度
- 限制调整次数，防止无限循环

### 2. 武将选择界面恢复

**修改内容**：
- 恢复了`ShowTabListInFrame`界面显示
- 增加了异常处理，如果界面显示失败会自动回退到自动招募
- 保留了GPU异常的安全处理机制

**新的界面显示逻辑**：
```csharp
try
{
    // 尝试显示招募界面
    gameScreen.ShowTabListInFrame(
        UndoneWorkKind.Frame, 
        FrameKind.Person, 
        FrameFunction.PersonManualHire,
        false, true, true, false,
        recommendedPersons, 
        null, 
        "军师推荐招募", 
        "Ability"
    );
    
    // 设置确认回调
    gameScreen.Plugins.GameFramePlugin.SetOKFunction(new GameDelegates.VoidFunction(() => {
        HandleRecruitmentConfirm(gameScreen, faction);
    }));
}
catch (Exception showEx)
{
    // 如果界面显示失败，回退到自动招募
    var bestPerson = recommendedPersons.GameObjects
        .Cast<Person>()
        .OrderByDescending(p => p.Command + p.Intelligence + p.Politics + p.Glamour)
        .FirstOrDefault();
    
    if (bestPerson != null)
    {
        bool recruitSuccess = PerformRecruitment(bestPerson, faction);
        ShowRecruitmentResult(gameScreen, faction, bestPerson, recruitSuccess, "");
    }
}
```
