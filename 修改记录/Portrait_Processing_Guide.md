# 三国志头像处理功能使用指南

## 功能概述

本功能将原来需要手动准备两张图片（大图和小图）的流程简化为只需要一张大图，程序会自动生成对应的小图。

### 原来的方式
- 需要手动准备两张图片：
  - `10000.jpg` - 大图，用于人物详情显示
  - `10000s.jpg` - 小图，用于部队头像显示

### 现在的方式
- 只需要准备一张大图：
  - `10000.jpg` - 大图
- 程序会自动生成：
  - `10000s.jpg` - 64x64像素的小图，使用高质量缩放算法

## 使用方法

### 1. 游戏运行时自动生成
当游戏运行时，如果发现某个人物只有大图没有小图，会自动从大图生成小图并保存到磁盘。

### 2. 使用编辑器批量处理
在编辑器中，通过菜单 `功能 -> 头像处理` 可以进行批量操作：

#### 生成功能
- **生成所有缺失的小图** - 处理默认头像和玩家头像目录
- **生成默认头像小图** - 只处理默认头像目录
- **生成玩家头像小图** - 只处理玩家头像目录

#### 清理功能
- **清理默认头像小图** - 删除所有默认头像的小图文件
- **清理玩家头像小图** - 删除所有玩家头像的小图文件

### 3. 使用批处理文件
运行 `generate_small_portraits.bat` 可以批量处理所有头像目录。

### 4. 使用命令行工具
```bash
# 生成所有缺失的小图
PortraitTool.exe generate

# 生成指定目录的小图
PortraitTool.exe generate "路径/到/头像目录"

# 清理指定目录的小图
PortraitTool.exe clean "路径/到/头像目录"

# 显示帮助
PortraitTool.exe help
```

## 技术细节

### 小图规格
- 尺寸：64x64像素
- 格式：JPEG
- 质量：85%
- 缩放算法：高质量双三次插值

### 查找优先级
程序按以下顺序查找头像文件：
1. 玩家自定义头像（Player目录）
2. MOD头像
3. 头像包头像
4. 默认头像（Default目录）
5. 通用默认头像

### 自动生成逻辑
当需要小图但文件不存在时：
1. 检查对应的大图是否存在
2. 如果存在，自动生成小图并保存
3. 如果生成成功，返回小图路径
4. 如果失败，继续查找其他可用图片

## 注意事项

1. **备份重要文件** - 在进行批量操作前，建议备份重要的头像文件
2. **文件命名规则** - 小图文件名为大图文件名加"s"后缀
3. **支持格式** - 目前只支持JPG格式的头像文件
4. **性能考虑** - 首次生成大量小图可能需要一些时间
5. **磁盘空间** - 每个小图大约占用10-20KB空间

## 故障排除

### 常见问题

**Q: 为什么某些头像没有自动生成小图？**
A: 检查原始大图文件是否存在且格式正确，确保有足够的磁盘空间和写入权限。

**Q: 生成的小图质量不理想怎么办？**
A: 可以手动创建更高质量的小图，程序会优先使用已存在的文件。

**Q: 如何恢复到原来的双图模式？**
A: 删除相关的自动生成代码，或者确保所有需要的小图都已手动创建。
