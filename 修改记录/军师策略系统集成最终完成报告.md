## 系统功能特点

### 智能人员推荐
- **搜索**：推荐智力最高的人员
- **流言**：推荐魅力+智力最高的人员
- **破坏**：推荐武力+智力最高的人员
- **煽动**：推荐魅力最高的人员
- **暗杀**：推荐武力+智力最高的人员（成功率较低）
- **劫牢**：推荐武力+智力最高的人员
- **说服**：推荐魅力+智力最高的人员
- **情报**：推荐智力最高的人员

### 动态成功率计算
- 基于执行人员的相关属性
- 考虑策略难度和风险
- 不同策略有不同的计算公式
- 成功率范围：5%-95%

### 个性化建议文本
- 多种建议文本随机选择
- 根据成功率调整语气
- 体现军师的智慧和谨慎
- 无军师时提供基础建议

## 使用流程

### 玩家体验流程
1. **右键点击建筑** → 选择策略菜单
2. **点击具体策略** → 自动显示军师建议对话框
3. **查看建议内容** → 了解推荐人员和成功率
4. **点击确认** → 进入原有的人员选择界面
5. **选择执行人员** → 完成策略执行

### 技术调用流程
```csharp
// 菜单点击 → 显示军师建议
Session.MainGame.mainGameScreen.ShowSearchAdvice();

// 军师建议 → 调用核心系统

// 显示建议 → 使用游戏原生对话框
this.xianshishijiantupian(speaker, message, ...);

// 继续原流程 → 显示人员选择界面
this.ShowTabListInFrame(...);
```
