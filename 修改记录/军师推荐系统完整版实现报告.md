### 核心算法

#### 1. 成功率计算 ✅
```
成功率 = 基础成功率 + (军师智力 - 智力门槛) × 智力加成
最终成功率 = Math.Min(100, Math.Max(0, 计算结果))
```

**示例**:
- 智力75: 50%成功率
- 智力80: 60%成功率
- 智力90: 80%成功率
- 智力100: 100%成功率

#### 2. 候选人评估算法 ✅
```csharp
综合能力值 = 智力×3 + 政治×2 + 统率×2 + 武力×1 + 技能加成 + 年龄加成
```

**年龄加成**:
- <25岁: +20分 (年轻有潜力)
- 25-35岁: +10分 (正值壮年)
- 35-50岁: 0分 (中年无加成)
- >50岁: -10分 (年老扣分)

**技能加成**: 每个技能的Merit值累加

#### 3. 加权随机选择 ✅
- 将候选人能力值转换为权重
- 能力越高，被选中概率越大
- 保证最低权重为1，避免零概率

### 推荐流程

#### 完整推荐流程 ✅
1. **冷却检查**: 验证是否在冷却期内
2. **基础验证**: 检查军师存在且存活
3. **智力门槛**: 验证军师智力≥75
4. **候选人搜寻**: 在已知区域搜寻在野武将
5. **数量检查**: 确认有可用候选人
6. **智力检定**: 基于成功率进行随机判定
7. **人才选择**: 使用加权算法选择最佳候选人
8. **统计更新**: 记录推荐结果到全局统计

#### 失败补偿机制 ✅
- **军师奖励**: 增加配置的功绩点数
- **城市奖励**: 提升所在城市治安度
- **上限保护**: 不会超过城市治安上限
- **日志记录**: 详细的补偿发放日志
