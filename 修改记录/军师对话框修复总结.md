# 军师对话框修复总结

## 问题描述
军师对话框只弹出简单的确认框，没有显示军师头像和对话内容。

## 根本原因
原来的实现使用了错误的调用顺序和方法，没有按照正确的模式来显示带军师头像的对话框。

## 解决方案
参考现有成功的对话实现（如`MGSPersonText.cs`中的例子），使用正确的调用顺序：

### 正确的调用顺序
1. **设置对话内容**: `advisor.TextResultString = advisorMessage`
2. **设置确认对话框**: `tupianwenziPlugin.SetConfirmationDialog()`
3. **设置对话框位置**: `ConfirmationDialogPlugin.SetPosition(ShowPosition.Center)`
4. **设置游戏对象分支**: `tupianwenziPlugin.SetGameObjectBranch()`
5. **显示对话框**: `tupianwenziPlugin.IsShowing = true`

## 修改内容

### 1. 军师支持对话框 (`ShowAdvisorSupportConfirmationDialog`)
```csharp
// 1. 设置对话内容
advisor.TextResultString = advisorMessage;

// 2. 设置确认对话框回调
this.Plugins.tupianwenziPlugin.SetConfirmationDialog(
    this.Plugins.ConfirmationDialogPlugin,
    yesCallback,
    noCallback
);

// 3. 设置对话框位置
this.Plugins.ConfirmationDialogPlugin.SetPosition(ShowPosition.Center);

// 4. 设置游戏对象分支（显示军师头像）
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    advisor,
    advisor,
    TextMessageKind.InformationSuccess,    // 军师支持使用InformationSuccess
    "AdvisorSupportConvince"
);

// 5. 显示对话框
this.Plugins.tupianwenziPlugin.IsShowing = true;
```

### 2. 军师劝阻对话框 (`ShowAdvisorDissuasionConfirmationDialog`)
使用相同的模式，但使用`TextMessageKind.AdvisorWarning`和不同的事件名称。

## 关键修复点

### 1. 移除了错误的位置设置
- **错误**: `tupianwenziPlugin.SetPosition(ShowPosition.Bottom, this)`
- **正确**: 只设置`ConfirmationDialogPlugin.SetPosition(ShowPosition.Center)`

### 2. 正确的调用顺序
- **错误**: 先调用`SetGameObjectBranch`再设置位置
- **正确**: 先设置回调和位置，再调用`SetGameObjectBranch`

### 3. 使用正确的消息类型
- 军师支持: `TextMessageKind.InformationSuccess`
- 军师劝阻: `TextMessageKind.InformationFailure`

## 编译错误修复
- **问题**: `TextMessageKind.AdvisorSupport`和`TextMessageKind.AdvisorWarning`不存在
- **解决**: 使用现有的枚举值`InformationSuccess`和`InformationFailure`

## 对话内容

### 军师支持对话
```
主公，关于说服{目标人物}一事：

经过分析，我认为此次行动成功率较高（约{成功率}%）。

推荐派遣{推荐人选}前往执行。

主公意下如何？
```

### 军师劝阻对话
```
主公，关于说服{目标人物}一事：

经过分析，此次行动风险较高，成功率仅约{成功率}%。

即使派遣{推荐人选}前往，成功把握也不大。

臣建议主公三思而后行，此时贸然行动恐怕得不偿失。
```

## 用户选择

### 军师支持时的选择
- **是**: 采纳军师建议，使用推荐人选
- **否**: 自己选择执行人员

### 军师劝阻时的选择  
- **是**: 听从军师劝告，放弃说服行动
- **否**: 坚持执行，不顾军师劝阻
