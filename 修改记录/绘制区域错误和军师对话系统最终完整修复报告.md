# 绘制区域错误和军师对话系统最终完整修复报告

## 问题总结

用户报告了两个持续存在的问题：
1. **绘制区域无效错误**: `[CacheManager] 绘制区域无效: {X:1091 Y:472 Width:0 Height:0}`
2. **军师对话框不显示**: 点击策略菜单后没有弹出对话框，直接跳转到人员选择

## 🔧 问题根因分析

### 1. 绘制区域无效错误 ✅

**根本原因**: ArchitectureDetail插件中的进度条系统故意创建零尺寸矩形来"隐藏"进度条，但这些零尺寸矩形仍被传递给CacheManager.Draw方法

**具体分析**:
- 坐标(1091, 472)等来自建筑详情界面的进度条系统
- 当建筑属性值为0时（如统合、支配、耐久等），系统返回`new Rectangle(0, 0, 0, 0)`
- CacheManager现在正确检测并记录这些零尺寸矩形，但它们实际上是有意的设计
- 错误出现在ArchitectureDetail.cs的Switch22进度条绘制部分

### 2. 军师对话系统问题 ✅

**根本原因**: TriggerAdvisorAdvice方法使用了3参数版本的SetGameObjectBranch，但根据工作示例应该使用6参数版本

**具体分析**:
- 当前使用: `SetGameObjectBranch(speaker, speaker, adviceText)`
- 工作示例使用: `SetGameObjectBranch(speaker, speaker, adviceText, "", "", "")`
- 3参数版本可能存在兼容性问题，导致对话框无法正确显示

## 🔧 修复方案

### 1. 绘制区域错误修复

**修复位置**: `WorldOfTheThreeKingdoms/GamePlugins/ArchitectureDetail/ArchitectureDetail.cs`

**修复前代码**:
```csharp
if (Switch22 == "on")
{
    try
    {
        CacheManager.Draw(this.IntegrationBarTexture, this.IntegrationBar1DisplayPosition, this.Integration1DisplayPosition, Color.White, 0f, Vector2.Zero, SpriteEffects.None, 0.0196f);
        CacheManager.Draw(this.DominationBarTexture, this.DominationBar1DisplayPosition, this.Domination1DisplayPosition, Color.White, 0f, Vector2.Zero, SpriteEffects.None, 0.0196f);
        // ... 其他进度条
    }
    catch { }
}
```

**修复后代码**:
```csharp
if (Switch22 == "on")
{
    try
    {
        // 修复：只绘制非零尺寸的进度条，避免绘制区域无效错误
        var integrationRect = this.Integration1DisplayPosition;
        if (integrationRect.Width > 0 && integrationRect.Height > 0)
        {
            CacheManager.Draw(this.IntegrationBarTexture, this.IntegrationBar1DisplayPosition, integrationRect, Color.White, 0f, Vector2.Zero, SpriteEffects.None, 0.0196f);
        }
        
        var dominationRect = this.Domination1DisplayPosition;
        if (dominationRect.Width > 0 && dominationRect.Height > 0)
        {
            CacheManager.Draw(this.DominationBarTexture, this.DominationBar1DisplayPosition, dominationRect, Color.White, 0f, Vector2.Zero, SpriteEffects.None, 0.0196f);
        }
        
        // ... 对所有进度条应用相同的零尺寸检查
    }
    catch { }
}
```

**修复原理**:
- 在调用CacheManager.Draw之前检查矩形尺寸
- 只有当Width > 0且Height > 0时才进行绘制
- 保持原有的隐藏逻辑，但避免传递零尺寸矩形给CacheManager

### 2. 军师对话系统修复

System.Diagnostics.Debug.WriteLine("[TriggerAdvisorAdvice] 准备调用SetGameObjectBranch");

## 📋 技术细节

### ArchitectureDetail进度条系统工作原理

1. **进度条计算**: 每个进度条根据当前值和最大值计算宽度
   ```csharp
   Math.Max(1, this.DominationBar1Client.Width * this.ShowingArchitecture.Domination / this.ShowingArchitecture.DominationCeiling)
   ```

2. **零值处理**: 当值为0或最大值为0时，返回零尺寸矩形
   ```csharp
   if (this.ShowingArchitecture.Domination == 0 || this.ShowingArchitecture.DominationCeiling == 0)
   {
       return new Rectangle(0, 0, 0, 0);
   }
   ```

3. **坐标计算**: DisplayOffset + Client位置确定最终绘制坐标
   ```csharp
   this.DominationBar1Client.X + this.DisplayOffset.X, this.DominationBar1Client.Y + this.DisplayOffset.Y
   ```

### 对话框系统SetGameObjectBranch重载版本

1. **3参数版本**: `SetGameObjectBranch(person, gameObject, branchName)`
2. **4参数版本**: `SetGameObjectBranch(person, gameObject, kind, branchName)`
3. **6参数版本**: `SetGameObjectBranch(person, gameObject, branchName, tupian, shengyin, TryToShowString)`

工作示例都使用4参数或6参数版本，3参数版本可能存在兼容性问题。
