# 情报功能映射错误修复报告

## 🎯 问题描述

用户反馈：点击"情报"菜单后出现的是"搜索"画面，功能映射错误。

## 🔍 问题分析

### 原因分析
1. **错误的策略映射**: 在 `MGSContextMenu.cs` 中，`ContextMenuResult.Tactics_Information` 被错误地映射到了 `StrategyKind.Search`
2. **情报功能特殊性**: 情报功能有自己独特的处理流程，不应该使用军师建议系统
3. **策略枚举不完整**: `StrategyKind` 枚举缺少 `JailBreak` 类型

### 错误的代码
```csharp
case ContextMenuResult.Tactics_Information:
    // 错误：将情报映射到搜索
    Session.MainGame.mainGameScreen.TriggerAdvisorAdvice(global::GameManager.StrategyKind.Search);
    break;
```

## ✅ 修复方案

### 1. 恢复情报功能的原始处理逻辑

**修复前**:
```csharp
case ContextMenuResult.Tactics_Information:
    Session.MainGame.mainGameScreen.TriggerAdvisorAdvice(global::GameManager.StrategyKind.Search);
    break;
```

**修复后**:
```csharp
case ContextMenuResult.Tactics_Information:
    // 恢复原始的情报处理逻辑
    this.ShowTabListInFrame(UndoneWorkKind.Frame, FrameKind.InformationKind, FrameFunction.GetInformationKind, false, true, true, false, Session.Current.Scenario.GameCommonData.AllInformationKinds.GetAvailList(this.CurrentArchitecture), null, "情报种类", "");
    break;
```

### 2. 完善策略枚举

**添加 JailBreak 策略类型**:
```csharp
public enum StrategyKind
{
    Gossip,         // 流言 (需高智力)
    Arson,          // 放火 (需高智力)
    Destruction,    // 破坏 (需高统率/智力)
    Instigate,      // 离间 (需高智力+魅力)
    Alliance,       // 结盟 (需高魅力/政治)
    Search,         // 搜索 (需高魅力/智力)
    JailBreak       // 劫牢 (需高武力/统率) - 新增
}
```

### 3. 更新军师建议文本

**新增劫牢建议**:
```csharp
case global::GameManager.StrategyKind.JailBreak:
    return $"{speakerTitle}：主公，劫牢救人需要勇武之士，请谨慎派遣。";
```

**修正暗杀建议**:
```csharp
case global::GameManager.StrategyKind.Arson:
    return $"{speakerTitle}：主公，暗杀行动凶险万分，需选择武艺高强者。";
```

### 4. 完善人员选择逻辑

**新增劫牢人员选择**:
```csharp
case global::GameManager.StrategyKind.JailBreak:
    this.Plugins.TabListPlugin.SetSelectedItemMaxCount(this.CurrentArchitecture.JailBreakPersonMaxCount);
    this.ShowTabListInFrame(UndoneWorkKind.Frame, FrameKind.Work, FrameFunction.GetJailBreakPerson, false, true, true, true, this.CurrentArchitecture.PersonsExcludeNvGuan, null, "劫狱", "劫狱");
    break;
```

### 5. 修正劫牢菜单映射

**修复前**:
```csharp
case ContextMenuResult.Tactics_JailBreak:
    Session.MainGame.mainGameScreen.TriggerAdvisorAdvice(global::GameManager.StrategyKind.Alliance);
    break;
```

**修复后**:
```csharp
case ContextMenuResult.Tactics_JailBreak:
    Session.MainGame.mainGameScreen.TriggerAdvisorAdvice(global::GameManager.StrategyKind.JailBreak);
    break;
```
