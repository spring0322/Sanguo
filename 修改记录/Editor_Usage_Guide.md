# 《三国志世界》修改器使用指南

## 概述

WorldOfTheThreeKingdomsEditor 是《三国志世界》的官方修改器，允许玩家编辑剧本数据，包括人物、势力、建筑、事件等各种游戏元素。

## 启动修改器

### 方法一：使用启动脚本（推荐）
```bash
# 首次使用，运行设置脚本
setup_editor.bat

# 启动修改器
run_editor.bat
```

### 方法二：直接运行
```bash
WorldOfTheThreeKingdomsEditor\bin\Debug\WorldOfTheThreeKingdomsEditor.exe
```

## 基本使用流程

### 1. 打开剧本
- 启动修改器后，使用 `Ctrl+O` 或菜单 `文件 -> 打开` 
- 选择 `Content\Data\Scenario` 目录下的 `.json` 剧本文件
- 推荐从以下剧本开始：
  - `184DHZS.json` - 184年 东汉末年
  - `194QXGJ.json` - 194年 群雄割据
  - `208CBZZ.json` - 208年 赤壁之战

### 2. 编辑数据
修改器提供多个标签页，每个对应不同的游戏数据：

#### 核心数据标签页：
- **人物** - 编辑武将属性、能力值、关系等
- **势力** - 编辑势力信息、外交关系等
- **建筑** - 编辑城池属性、设施等
- **事件** - 编辑历史事件和触发条件

#### 基础数据标签页：
- **技能** - 武将技能定义
- **特技** - 武将特技定义
- **官爵** - 官职系统
- **宝物** - 宝物属性

### 3. 编辑操作
- **双击行** - 编辑选中的条目
- **右键菜单** - 添加、编辑、删除条目
- **Ctrl+C/Ctrl+V** - 复制粘贴数据
- **Delete** - 删除选中条目

### 4. 保存剧本
- 使用 `Ctrl+S` 或菜单 `文件 -> 保存`
- 选择保存位置和文件名
- 修改器会同时更新 `CommonData.json` 和 `Scenarios.json`

## 高级功能

### 随机化功能
修改器提供多种随机化工具：
- **随机化势力** - 重新分配势力的城池
- **随机化武将相性** - 随机化武将的政治倾向
- **随机化武将性格** - 随机化武将的性格特征
- **随机化武将寿命** - 随机化武将的生死年份
- **随机化武将年龄** - 调整武将的出生年份

### 数据导出
- **导出到 Excel** - 将剧本数据导出为 Excel 文件
- **导出地形信息** - 导出地图数据为文本文件

### 批量操作
- **复制粘贴** - 支持从 Excel 等外部工具批量导入数据
- **全选** - `Ctrl+A` 选择所有数据
- **批量删除** - 选中多行后按 Delete 键

## 注意事项

### 数据完整性
1. **ID 唯一性** - 确保所有 ID 在同类型对象中唯一
2. **关系一致性** - 人物关系（父子、夫妻等）需要双向一致
3. **势力归属** - 确保武将和建筑正确归属于势力

### 备份建议
1. 编辑前备份原始剧本文件
2. 重要修改后及时保存
3. 定期备份整个 `Content\Data` 目录

### 性能优化
1. 大型剧本编辑时可能较慢，请耐心等待
2. 避免同时打开过多标签页
3. 定期重启修改器以释放内存

## 常见问题

### Q: 修改器启动失败
A: 
1. 确保安装了 .NET Framework 4.8
2. 检查 `CommonData.json` 文件是否存在
3. 运行 `setup_editor.bat` 进行环境检查

### Q: 无法打开剧本文件
A:
1. 确保文件格式为 `.json`
2. 检查文件是否损坏
3. 尝试打开其他剧本文件

### Q: 保存后游戏无法识别剧本
A:
1. 确保保存在正确的 `Content\Data\Scenario` 目录
2. 检查 `Scenarios.json` 是否正确更新
3. 使用修改器的"同步剧本"功能

### Q: 修改的数据在游戏中不生效
A:
1. 确保保存了所有修改
2. 重启游戏重新加载数据
3. 检查数据格式是否正确

## 技巧和建议

### 新手建议
1. 从简单的属性修改开始（如武将能力值）
2. 熟悉界面后再尝试复杂的关系编辑
3. 经常保存，避免数据丢失

### 高级技巧
1. 使用 Excel 进行大批量数据处理
2. 利用随机化功能创建有趣的剧本变体
3. 结合历史资料创建更真实的剧本

### 创意玩法
1. 创建架空历史剧本
2. 制作特殊能力的武将
3. 设计独特的势力平衡

## 相关文件

- `WorldOfTheThreeKingdomsEditor.exe` - 修改器主程序
- `Content\Data\Common\CommonData.json` - 游戏基础数据
- `Content\Data\Scenario\*.json` - 剧本文件
- `Content\Data\Scenario\Scenarios.json` - 剧本索引文件

## 更新和维护

修改器会随游戏本体更新，如遇到兼容性问题：
1. 检查是否有新版本的修改器
2. 备份数据后重新安装
3. 参考官方文档或社区支持
