- **67-99%**: "此建筑防御薄弱，破坏成功的概率很高。"
- **100%**: "此建筑防御空虚，破坏行动万无一失！"

#### 成功率计算算法
```csharp
private int CalculateDestroySuccessRate(Person executor, Architecture target)
{
    int targetDefense = target.Domination * 8;
    int executorAbility = executor.DestroyAbility;
    
    if (executorAbility <= 150) return 0; // 能力太低
    
    double successRate = (double)executorAbility / (executorAbility + targetDefense) * 100;
    return Math.Max(0, Math.Min(100, (int)successRate));
}
```

## 完整的用户流程

### 智能破坏流程
1. **入口**: 右键建筑 → 选择"破坏"
2. **目标选择**: 显示所有可破坏的目标建筑列表
3. **选择目标**: 玩家选择要破坏的具体建筑
4. **军师分析**: 系统分析最佳执行人员和成功率
5. **智能对话**: 根据成功率显示支持或劝阻对话
6. **用户决策**: 玩家选择是否采纳建议或坚持执行
7. **人员选择**: 显示执行人员选择界面（可能预选推荐人员）
8. **执行破坏**: 选择人员后直接执行破坏任务

### 与原系统的区别
| 原破坏系统 | 智能破坏系统 |
|-----------|-------------|
| 先选人员，后选目标 | 先选目标，后选人员 |
| 无军师分析 | 完整的军师分析和建议 |
| 无智能推荐 | 自动推荐最佳执行人员 |
| 无成功率预测 | 基于能力的成功率计算 |
| 无对话交互 | 丰富的军师对话系统 |
