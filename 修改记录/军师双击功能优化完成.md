### 3. 事件处理阶段
```csharp
// 双击事件：检查空白地形并显示菜单
private void OnDoubleClickDetected(Point clickPosition)
{
    if (IsEmptyTerrainClick(clickPosition))
    {
        ShowAdvisorDoubleClickMenu(clickPosition);
    }
}

// 单击事件：处理菜单交互
private void OnLeftClickDetected(Point clickPosition)
{
    if (_advisorMenuManager?.IsMenuVisible == true)
    {
        _advisorMenuManager.HandleMenuClick(clickPosition);
    }
}
```

## 性能优化

### 1. 减少重复计算
- 使用`Stopwatch`替代`DateTime`计算，性能更好
- 使用`Vector2.Distance`替代手动计算距离
- 事件驱动减少不必要的检查

### 2. 内存优化
- 单例模式避免重复创建实例
- 及时重置状态避免内存泄漏
- 使用nullable类型减少内存占用

### 3. 代码可维护性
- 职责分离：双击检测独立于游戏逻辑
- 事件驱动：松耦合设计
- 可配置参数：支持动态调整双击阈值
