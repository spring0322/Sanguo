# 菜单显示优化修复

## 🎯 发现的问题

### 1. 重复绘制导致卡顿
```
[MenuUI] 成功绘制文字: 势力情报 在位置 {X:1304 Y:520}
[MenuUI] 成功绘制文字: 势力情报 在位置 {X:1304 Y:520}  ← 重复输出
[MenuUI] 成功绘制文字: 势力情报 在位置 {X:1304 Y:520}
```

**原因**: Draw 方法每帧都会调用，Console.WriteLine 导致大量日志输出

### 2. 只显示一个字
从截图看到只显示了"报"字，"势力情"三个字没有显示

**可能原因**: 
- 菜单宽度不够
- 文字位置计算有问题
- 字体大小与菜单尺寸不匹配

## ✅ 修复方案

### 1. 移除重复日志
```csharp
// 修复前 - 每帧都输出日志
Console.WriteLine($"[MenuUI] 成功绘制文字: {text} 在位置 {textPos}");

// 修复后 - 注释掉，避免卡顿
// Console.WriteLine($"[MenuUI] 成功绘制文字: {text} 在位置 {textPos}");
```

### 2. 调整菜单尺寸
```csharp
// 修复前 - 可能太宽或太高
private const int MENU_WIDTH = 220;
private const int MENU_ITEM_HEIGHT = 36;
private const int MENU_PADDING = 4;

// 修复后 - 适应中文显示
private const int MENU_WIDTH = 120;      // 适合4个中文字符
private const int MENU_ITEM_HEIGHT = 32; // 适合中文字体高度
private const int MENU_PADDING = 8;      // 增加内边距
```

### 3. 优化文字位置
```csharp
// 修复前 - 复杂的居中计算
Vector2 textPos = new Vector2(
    bounds.X + 10, 
    bounds.Y + (MENU_ITEM_HEIGHT - 24) / 2);

// 修复后 - 简单的左上角定位
Vector2 textPos = new Vector2(
    bounds.X + 8,  // 左边距8像素
    bounds.Y + 6); // 上边距6像素
```
