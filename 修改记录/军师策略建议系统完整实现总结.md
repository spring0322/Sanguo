# 军师策略建议系统完整实现总结

## 系统概述

军师策略建议系统是一个智能的游戏辅助功能，能够根据当前势力的人员配置和军师的智力水平，为玩家提供各种策略的执行建议，包括推荐最佳执行人选和预测成功率。

## 核心功能

### 1. 策略类型支持
- **流言** (Gossip) - 需要高智力人员
- **放火** (Arson) - 需要高智力人员  
- **破坏** (Destruction) - 需要统率和智力兼备
- **离间** (Instigate) - 需要高智力和魅力
- **结盟** (Alliance) - 需要高政治和魅力
- **搜索** (Search) - 需要高魅力和智力（魅力为主）

### 2. 智能推荐算法
- 根据策略类型自动选择最适合的执行人员
- 基于属性对抗计算真实成功率
- 军师智力影响预测准确度（智力越高误差越小）

### 3. 个性化军师点评
- 根据成功率生成不同的建议文本
- 特殊处理搜索策略的独特文本
- 支持无人可用时的提醒

## 使用方法

### 基础用法
```csharp
// 1. 获取当前势力和军师
var faction = Session.Current.Scenario.CurrentPlayer;
var advisor = faction?.Advisor;

// 2. 获取策略建议
var advice = AdvisorStrategySystem.GetAdvice(advisor, faction, targetEnemy, StrategyKind.Gossip);

// 3. 显示建议
string title = "军师谏言";
string content = advice.AdvisorComment;
if (advice.BestCandidate != null)
{
    content += $"\n(推荐执行人：{advice.BestCandidate.Name})";
}
ShowMessageBox(title, content);
```


```csharp
    if (advisor != null)
    {
        // 获取多种策略建议并比较
        var arsonAdvice = AdvisorStrategySystem.GetAdvice(advisor, faction, targetCity, StrategyKind.Arson);

        ShowMessage("攻城建议", bestAdvice.AdvisorComment);
    }
}
```

## 算法详解

### 人选推荐算法
1. **筛选可用人员**：排除俘虏、外出、生病等不可用人员
2. **按策略类型计算适合度**：
   - 流言/放火：纯智力
   - 破坏：统率60% + 智力40%
   - 离间：智力70% + 魅力30%
   - 结盟：政治50% + 魅力50%
   - 搜索：魅力60% + 智力40%
3. **选择最高分人员**

### 成功率计算算法
1. **搜索策略**：基础20% + (综合属性/2.5)%
2. **对人策略**：基础50% + 属性差值
3. **对城策略**：基础50% + (攻击属性 - 防御属性)
4. **军师预测误差**：根据军师智力添加随机误差

### 智力误差系统
```csharp
int errorRange = (110 - advisor.Intelligence);
if (errorRange < 5) errorRange = 5; // 最小5%误差
int noise = GameObject.Random(errorRange) - (errorRange / 2);
int predicted = realChance + noise;
```

## 扩展功能

### 1. 策略专长分析
系统可以分析军师在各个策略上的专长程度：
- ★★★ 极其擅长 (80%+)
- ★★☆ 比较擅长 (60%+)
- ★☆☆ 一般水平 (40%+)
- ☆☆☆ 不太擅长 (40%-)

可以一次性获取所有策略的建议，用于制定整体战略。

## 配置和定制


```csharp
// 例如调整搜索的基础成功率
baseChance = 30 + (int)(attrFactor / 2.0f); // 提高基础成功率
```
