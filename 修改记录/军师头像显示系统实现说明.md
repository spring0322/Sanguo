# 军师头像显示系统实现说明

## 实现时间
2025年12月21日

## 功能描述
在游戏主界面固定位置显示当前玩家的军师头像，如果没有军师则显示9999编号的默认头像。

## 实现方案

### 1. 技术架构
- **绘制方式**: 借鉴火焰系统的安全绘制方式，使用`CacheManager.DrawZhsanAvatar`
- **位置**: 屏幕固定坐标 (300, 150)，尺寸 100x100 像素
- **绘制深度**: 0.001f，确保在其他UI元素之上
- **异常处理**: 多层try-catch保护，静默处理异常

### 2. 核心代码结构

#### 2.1 字段定义
```csharp
/// <summary>
/// 军师头像显示区域
/// </summary>
private Rectangle _advisorPortraitRect = new Rectangle(300, 150, 100, 100);
```

#### 2.2 主绘制方法
```csharp
private void DrawAdvisorPortrait()
```
- 检查当前玩家是否存在
- 获取军师ID
- 如果有军师：绘制军师头像
- 如果没有军师：调用9999编号的默认头像

#### 2.3 默认头像绘制
```csharp
private void DrawDefaultAdvisorPortrait()
```
- 使用`CacheManager.DrawZhsanAvatar(9999, ...)`绘制9999编号头像
- 如果9999头像也加载失败，调用兜底图标

#### 2.4 兜底图标
```csharp
private void DrawFallbackIcon()
```
- 绘制简单的灰色边框矩形
- 作为最后的兜底方案

### 3. 调用位置
在`MainGameScreen.cs`的`Drawing(GameTime gameTime)`方法中调用：
```csharp
// 【军师头像显示】借鉴火焰系统的安全绘制方式
DrawAdvisorPortrait();
```

### 4. 头像显示逻辑

#### 情况1：有军师
```
Session.Current.Scenario.CurrentPlayer.AdvisorID > 0
且军师存在于Persons集合中
→ 显示军师的实际头像
```

#### 情况2：没有军师
```
AdvisorID <= 0 或军师不存在
→ 显示9999编号的默认头像
```

#### 情况3：9999头像加载失败
```
9999头像不存在或加载失败
→ 显示灰色边框占位符
```

### 5. 安全特性

#### 5.1 多层异常保护
- 外层try-catch保护整个绘制流程
- 内层try-catch保护默认头像绘制
- 最内层try-catch保护兜底图标绘制

#### 5.2 空引用检查
- 检查Session.Current
- 检查Scenario
- 检查CurrentPlayer
- 检查Persons集合
- 检查HasGameObject

#### 5.3 静默异常处理
- 所有异常都静默处理，不会导致游戏崩溃
- 类似火焰系统的异常处理方式

### 6. 使用的API

#### CacheManager.DrawZhsanAvatar (Person版本)
```csharp
CacheManager.DrawZhsanAvatar(
    Person advisor,           // 军师对象
    Rectangle rect,           // 绘制区域
    float depth,              // 绘制深度
    PortraitSize size,        // 头像尺寸
    Color color               // 颜色
)
```

#### CacheManager.DrawZhsanAvatar (int版本)
```csharp
CacheManager.DrawZhsanAvatar(
    int index,                // 头像ID (9999)
    Rectangle rect,           // 绘制区域
    float depth,              // 绘制深度
    PortraitSize size,        // 头像尺寸
    Color? color,             // 颜色
    PortraitDefaultType? type // 默认类型
)
```

### 7. 优势分析

✅ **不需要额外UI素材** - 使用游戏现有的头像系统
✅ **风格统一** - 与游戏其他头像显示保持一致
✅ **安全可靠** - 借鉴火焰系统的成熟绘制方式
✅ **多层兜底** - 有军师→9999头像→灰色占位符
✅ **性能优化** - 使用CacheManager的缓存机制
✅ **易于扩展** - 为后续点击交互功能预留接口
