# 双击系统字体重复初始化问题修复

## 🐛 问题描述

字体一直重复初始化，导致性能问题：
```
[TextManager] 开始初始化字体: Content\Font\FZLB_GBK.TTF, 大小: 30
[TextManager] 字体文件加载成功，大小: 14155800 字节
[TextManager] 字体初始化成功
[TextManager] 开始初始化字体: Content\Font\FZLB_GBK.TTF, 大小: 30  ← 重复！
[TextManager] 字体文件加载成功，大小: 14155800 字节
[TextManager] 字体初始化成功
```

## 🔍 问题根源

发现了两个调用点都在初始化字体：

1. **InitializeGraphics()** - 在系统初始化时调用 `LoadGameFont()`
2. **ShowMenu()** - 每次显示菜单时检查并调用 `LoadGameFont()`

这导致字体被重复初始化。

## ✅ 修复方案

### 1. 移除 InitializeGraphics 中的字体加载
```csharp
private void InitializeGraphics()
{
    try
    {
        var gd = Session.MainGame.GraphicsDevice;
        _menuBackground = CreateColorTexture(gd, new Color(40, 40, 40, 255)); 
        _menuItemNormal = CreateColorTexture(gd, new Color(255, 255, 255, 255)); 
        _menuItemHover = CreateColorTexture(gd, new Color(100, 149, 237, 180)); 
        
        // [修复] 不在这里调用 LoadGameFont()
        // 字体在 ShowMenu 时按需加载
    }
    catch { }
}
```

### 2. 优化 ShowMenu 中的字体检查
```csharp
public void ShowMenu(List<AdvisorMenuItem> items, Point position, GameTime gameTime)
{
    if (items == null || items.Count == 0) return;

    // [优化] 只在第一次或字体为空时才尝试获取字体
    if (_menuFont == null)
    {
        LoadGameFont();
    }
    
    // ... 其他代码
}
```

### 3. 增强 LoadGameFont 的检查逻辑
```csharp
private void LoadGameFont()
{
    // 方案1: 检查 TextManager.font 是否已存在
    if (TextManager.font != null)
    {
        _menuFont = TextManager.font;
        Console.WriteLine("✅ [MenuUI] 使用现有 TextManager.font");
        return;
    }
    
    // 方案2: 只在 TextManager.font 为空时才初始化
    if (TextManager.font == null && CacheManager.FontPair.Name != null)
    {
        Console.WriteLine("[MenuUI] TextManager.font 为空，尝试初始化");
        TextManager.Init(CacheManager.FontPair.Name, CacheManager.FontPair.Size);
        // ...
    }
    
    // ... 其他备用方案
}
```

## 📊 修复效果

### 修复后

- ✅ 后续使用缓存的字体对象

## 📝 技术细节

### 字体加载流程
1. 游戏启动时，Session 初始化 TextManager
2. TextManager.Init() 加载字体文件并创建 DynamicSpriteFont
3. 双击菜单系统检测到 TextManager.font 已存在
4. 直接使用现有字体，不重复初始化

### 性能优化
- **内存**: 避免重复加载 14MB 字体文件
- **CPU**: 避免重复解析 TTF 字体
- **响应**: 菜单显示更快速
