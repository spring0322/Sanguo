## 🎯 修复策略

## 🔧 修复内容

### 1. 启用StrategistUI的Update方法
在 `MainGameScreen.cs` 中取消注释：
```csharp
// 更新军师UI系统
if (_strategistUI != null && Session.Current?.Scenario != null)
{
    _strategistUI.Update(gameTime);
    // 定期更新军师按钮（每60帧更新一次）
    if (_globalFrameCounter % 60 == 0)
    {
        _strategistUI.UpdateAdvisorButtonSafe(Session.Current.Scenario, Platform.GraphicsDevice);
    }
}
```

### 2. 简化按钮点击处理
移除了复杂的条件检查，直接调用游戏现有的军师任命界面：

```csharp
private void OnAdvisorButtonClicked()
{
    var faction = Session.Current?.Scenario?.CurrentPlayer;
    if (faction == null) return;

    var candidates = faction.AdvisorCandicate;
    if (candidates == null || candidates.Count == 0) return;

    // 直接调用MainGameScreen的ShowTabListInFrame方法
    var mainGameScreen = Session.MainGame?.mainGameScreen;
    if (mainGameScreen != null)
    {
        string title = faction.Advisor != null ? "重新任命军师" : "任命军师";
        
        mainGameScreen.ShowTabListInFrame(
            UndoneWorkKind.Frame,
            FrameKind.Person,
            FrameFunction.AppointAdvisor,
            false, true, true, false,
            candidates,
            null,
            title,
            ""
        );
    }
}
```
