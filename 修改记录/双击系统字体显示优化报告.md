# 双击系统字体显示优化报告

## 问题描述
用户反馈"锦囊妙计"只显示"计"字，而双击建筑时"驻城军师"四个字能正常显示。

## 问题分析

### 对比分析
- **问题菜单**: "锦囊妙计" (4字) - 只显示"计"
- **正常菜单**: "驻城军师" (4字) - 完整显示
- **参考菜单**: 城池左键菜单中的"委任工作"、"自动出征"等4字菜单项正常显示

### 可能原因
1. **菜单宽度不足**: 原配置Width="160"可能不够
2. **文字位置偏移**: 左边距过大导致文字被截断
3. **绘制区域限制**: 菜单项的实际绘制区域小于预期
4. **字体大小问题**: 字体过大导致4字无法完整显示

## 优化措施

### 1. 配置文件优化
```xml
<!-- 原配置 -->
<MenuKind ID="12" Width="120" Height="27">

<!-- 优化后 -->
<MenuKind ID="12" Width="160" Height="27">
```

### 2. 代码优化
```csharp
// 原设置
private const int MENU_WIDTH = 140;
Vector2 textPos = new Vector2(bounds.X + 8, bounds.Y + 6);

// 优化后
private const int MENU_WIDTH = 160;
Vector2 textPos = new Vector2(bounds.X + 6, bounds.Y + 8);
```

### 3. 调试信息增强
添加了详细的绘制日志：
```csharp
Console.WriteLine($"[MenuUI] 绘制文字: '{text}' 位置: {textPos} 菜单区域: {bounds}");
```

## 技术细节

### 菜单宽度对比
- **城池左键菜单**: Width="100" - 能正常显示4字
- **双击军师菜单**: Width="160" - 应该有足够空间
- **部队左键菜单**: Width="100" - 参考标准

### 文字定位优化
- **左边距**: 从8px减少到6px，增加文字显示空间
- **上边距**: 从6px增加到8px，改善垂直居中效果
- **总可用宽度**: 160 - 6 - 8(右边距) = 146px

### 字符宽度估算
- **中文字符**: 约13px/字 (FontSize=13)
- **4个中文字**: 约52px
- **可用空间**: 146px >> 52px (足够显示)

## 后续监控

### 需要验证的点
1. 双击空地显示"锦囊妙计"是否完整
2. 双击建筑显示"驻城军师"是否正常
3. 子菜单"任命军师"、"罢免军师"等是否完整显示
4. 菜单边界是否正确避让屏幕边缘

### 如果问题仍存在
可能需要进一步调查：
1. CacheManager.DrawString的具体实现
2. 字体渲染的裁剪机制
3. SpriteBatch的绘制区域限制
4. 游戏原生菜单系统的实现差异

## 总结
通过增加菜单宽度到160px并优化文字定位，应该能解决"锦囊妙计"只显示"计"字的问题。如果问题仍然存在，说明可能是更深层的字体渲染机制问题，需要进一步分析CacheManager的实现。
