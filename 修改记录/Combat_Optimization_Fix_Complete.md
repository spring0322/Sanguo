## 修复的主要问题

### 1. 字段访问权限问题
**问题**: `_damageAccumulator` 字段为私有，但在 `MainGameScreen.cs` 中需要访问
**修复**: 将字段改为公共访问权限
```csharp
// 修复前
private float _damageAccumulator = 0f;

// 修复后  
public float _damageAccumulator = 0f;
```

### 2. 纹理 IsDisposed 属性问题
**问题**: `PlatformTexture` 类没有 `IsDisposed` 属性
**修复**: 移除所有 `IsDisposed` 检查，改用宽度/高度验证
```csharp
// 修复前
if (textureToUse != null && !textureToUse.IsDisposed && textureToUse.Width > 0)

// 修复后
if (textureToUse != null && textureToUse.Width > 0)
```

### 3. Person 类 Experience 属性问题
**问题**: `Person` 类没有直接的 `Experience` 属性
**修复**: 使用 `CommandExperienceIncrease` 属性
```csharp
// 修复前
this.Leader.Experience += damage / 100;

// 修复后
this.Leader.CommandExperienceIncrease += damage / 100;
```

### 4. Troop 类 Injury 属性问题
**问题**: `Troop` 类使用 `InjuryQuantity` 而不是 `Injury`
**修复**: 统一使用 `InjuryQuantity` 属性
```csharp
// 修复前
target.Injury += injuryIncrease;

// 修复后
target.InjuryQuantity += injuryIncrease;
```
