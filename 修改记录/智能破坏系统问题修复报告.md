# 智能破坏系统问题修复报告

## 修复的问题

### 问题1: 军师读取成了君主 ✅

**问题描述**: 
- 智能破坏系统中，GetBestAdvisor方法只是简单地选择智力最高的人物
- 没有优先使用势力指定的军师，导致经常选择君主而不是军师

**根本原因**:
```csharp
// 原来的错误实现
private Person GetBestAdvisor(Architecture architecture)
{
    Person bestAdvisor = null;
    int highestIntelligence = 0;
    foreach (Person person in architecture.Persons)
    {
        if (person.Intelligence > highestIntelligence)
        {
            highestIntelligence = person.Intelligence;
            bestAdvisor = person;
        }
    }
    return bestAdvisor;
}
```

**修复方案**:
```csharp
// 修复后的正确实现
private Person GetBestAdvisor(Architecture architecture)
{
    var faction = Session.Current.Scenario.CurrentPlayer;
    
    // 优先使用势力的指定军师
    if (faction?.Advisor != null)
    {
        return faction.Advisor;
    }
    
    // 其次使用建筑的军师
    if (architecture?.Advisor != null)
    {
        return architecture.Advisor;
    }
    
    // 再次使用势力君主
    if (faction?.Leader != null)
    {
        return faction.Leader;
    }
    
    // 最后选择智力最高的人物
    Person bestAdvisor = null;
    int highestIntelligence = 0;
    foreach (Person person in architecture.Persons)
    {
        if (person.Intelligence > highestIntelligence)
        {
            highestIntelligence = person.Intelligence;
            bestAdvisor = person;
        }
    }
    return bestAdvisor;
}
```

**修复效果**:
- ✅ 优先使用势力指定的军师
- ✅ 与智能说服系统保持一致的军师获取逻辑
- ✅ 确保对话显示的是军师而不是君主

### 问题2: 派遣完成后流程没有结束 ✅

**问题描述**:
- 选择执行人员并完成破坏/说服任务后，游戏再次弹出选择界面
- 旧的流程没有被正确清理，导致重复执行

**根本原因**:
- 在`FrameFunction_Architecture_AfterPersonManualHire`方法中，执行完任务后没有清理相关状态
- `CurrentGameObjects`、`CurrentPersons`等状态变量没有被重置
- 导致系统认为还有未完成的操作，继续弹出选择界面

**修复方案**:
```csharp
// 在说服操作完成后清理状态
if (isConvinceOperation && targetPerson != null)
{
    try
    {
        executor.GoForConvince(targetPerson);
        Session.MainGame.mainGameScreen.PlayNormalSound("Content/Sound/Tactics/Outside");
        
        // 清理状态，防止重复执行
        Session.MainGame.mainGameScreen.CurrentPerson = null;
        this.CurrentGameObjects = null;
        this.CurrentPersons = null;
        
        System.Diagnostics.Debug.WriteLine("[FrameFunction_Architecture_AfterPersonManualHire] 智能说服流程完成，状态已清理");
    }
    catch (Exception convinceEx)
    {
        System.Diagnostics.Debug.WriteLine($"[FrameFunction_Architecture_AfterPersonManualHire] 执行说服时出错: {convinceEx.Message}");
    }
}

// 在破坏操作完成后清理状态
else if (isDestroyOperation && targetArchitecture != null)
{
    try
    {
        executor.GoForDestroy(targetArchitecture.Position);
        Session.MainGame.mainGameScreen.PlayNormalSound("Content/Sound/Tactics/Outside");
        
        // 清理状态，防止重复执行
        // 注意：不要清理CurrentArchitecture，因为它可能是玩家当前选中的建筑
        this.CurrentGameObjects = null;
        this.CurrentPersons = null;
        
        System.Diagnostics.Debug.WriteLine("[FrameFunction_Architecture_AfterPersonManualHire] 智能破坏流程完成，状态已清理");
    }
    catch (Exception destroyEx)
    {
        System.Diagnostics.Debug.WriteLine($"[FrameFunction_Architecture_AfterPersonManualHire] 执行破坏时出错: {destroyEx.Message}");
    }
}
```

**修复效果**:
- ✅ 执行完成后正确清理状态变量
- ✅ 防止重复弹出选择界面
- ✅ 确保智能系统流程完整结束
- ✅ 保留原始PersonManualHire逻辑作为后备方案

## 技术细节

### 军师获取优先级
1. **势力指定军师** (`faction.Advisor`) - 最高优先级
2. **建筑军师** (`architecture.Advisor`) - 次优先级
3. **势力君主** (`faction.Leader`) - 第三优先级
4. **智力最高人物** - 最后选择

### 状态清理策略
- **说服操作**: 清理 `CurrentPerson`、`CurrentGameObjects`、`CurrentPersons`
- **破坏操作**: 清理 `CurrentGameObjects`、`CurrentPersons`（保留 `CurrentArchitecture`）
- **未知操作**: 使用原始 `PersonManualHire` 逻辑作为后备

### 异常处理
- 每个操作都有完整的try-catch异常处理
- 详细的调试输出，便于问题排查
- 出错时不会影响游戏的正常运行
