## 📊 候选人条件

根据完整流程代码，候选人必须满足：

```csharp
// Faction.AdvisorCandicate 属性

    p.BelongedCaptive == null && p.LocationTroop == null && p.Intelligence >= 70)
```

- ✅ 不是君主 (`p != this.Leader`)

- ✅ 人物可用 (`p.Available`)
- ✅ 人物存活 (`p.Alive`)
- ✅ 未被俘虏 (`p.BelongedCaptive == null`)
