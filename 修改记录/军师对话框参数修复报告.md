# 军师对话框参数修复报告

## 问题描述
军师对话框显示"AdvisorDissuasion"和"AdvisorSupport"而不是中文内容，导致用户看到的是英文标识符而不是实际的对话内容。

## 根本原因
`SetGameObjectBranch`方法的参数顺序错误：
- **错误用法**：将标识符（如"AdvisorSupport"）放在第3个参数位置，中文内容放在第6个参数位置
- **正确用法**：将中文对话内容直接放在第3个参数位置

## 修复内容

### 1. ShowAdvisorSupportConfirmationDialog方法修复
**文件位置**：`WorldOfTheThreeKingdoms/GameScreens/MainGameScreen.cs` (约第3464行)

**修复前**：
```csharp
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    advisor,                           // 说话人
    advisor,                           // 对象
    "AdvisorSupport",                  // 分支名称（错误）
    "",                                // 图片
    "",                                // 声音
    advisorMessage                     // TryToShowString - 中文内容（错误位置）
);
```

**修复后**：
```csharp
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    advisor,                           // 说话人
    advisor,                           // 对象
    advisorMessage,                    // 直接显示的中文对话内容（正确位置）
    "",                                // 图片
    "",                                // 声音
    ""                                 // 空字符串
);
```

### 2. ShowAdvisorDissuasionConfirmationDialog方法
**文件位置**：`WorldOfTheThreeKingdoms/GameScreens/MainGameScreen.cs` (约第3623行)

此方法在之前的修复中已经正确实现了参数顺序。

## 修复效果
1. **军师支持对话**：现在会显示类似"主公，关于说服XXX一事：经过分析，我认为此次行动成功率较高..."的中文内容
2. **军师劝阻对话**：现在会显示类似"主公，关于说服XXX一事：经过分析，此次行动风险较高..."的中文内容
3. **不再显示**："AdvisorSupport"或"AdvisorDissuasion"等英文标识符

## 参数说明
`SetGameObjectBranch`方法的正确参数顺序：
1. **说话人**：显示头像的人物对象
2. **对象**：通常与说话人相同
3. **对话内容**：直接显示的中文文本（关键修复点）
4. **图片**：头像图片文件名（可为空）
5. **声音**：语音文件名（可为空）
6. **额外文本**：通常为空字符串
