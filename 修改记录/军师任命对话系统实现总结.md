# 军师任命对话系统实现总结

## 系统概述

实现了完整的军师任命对话系统，支持君主和军师之间的轮流对话，对话内容从配置文件读取，支持多种对话类型和智能匹配。

## 核心组件

### 1. DialogueManager.cs
- **位置**: `WorldOfTheThreeKingdoms/GameManager/DialogueManager.cs`
- **功能**: 对话管理器，负责加载配置、匹配对话、显示轮流对话
- **主要方法**:
  - `Initialize()` - 初始化加载所有对话配置
  - `GetDialogue()` - 获取最佳匹配的对话
  - `ShowAppointDialogue()` - 显示任命对话序列
  - `ShowRecallDialogue()` - 显示罢免对话序列

### 2. 对话配置文件
- **位置**: `Content/Data/Dialogues/`
- **文件**:
  - `AdvisorAppointment.xml` - 任命成功对话
  - `AdvisorRefusal.xml` - 任命拒绝对话  
  - `AdvisorRecall.xml` - 罢免对话

### 3. 对话数据结构
```csharp
public class DialogueEntry
{
    public DialogueType Type { get; set; }
    public string LeaderText { get; set; }      // 君主对话
    public string AdvisorText { get; set; }     // 军师对话
    public string LeaderPersonality { get; set; }  // 君主性格匹配
    public string AdvisorPersonality { get; set; } // 军师性格匹配
    public int MinLeaderIntelligence { get; set; }  // 君主最低智力
    public int MinAdvisorIntelligence { get; set; } // 军师最低智力
}
```

## 对话匹配机制

### 智能匹配算法
1. **基础分数**: 每个对话条目都有基础分数1
2. **性格匹配**: 君主/军师性格匹配各加2分
3. **智力匹配**: 满足智力要求各加1分
4. **随机选择**: 同分数对话随机选择，增加多样性

### 匹配条件
- **MinLeaderIntelligence**: 君主最低智力要求
- **MinAdvisorIntelligence**: 军师最低智力要求
- **LeaderPersonality**: 君主性格要求（可选）
- **AdvisorPersonality**: 军师性格要求（可选）

## 对话类型

### 1. 任命成功对话 (Default)
- 8种不同风格的对话
- 根据智力高低匹配不同对话
- 包含谦逊、豪迈、礼贤下士等风格

### 2. 任命拒绝对话 (Refusal)  
- 7种拒绝理由
- 礼貌拒绝、高傲拒绝、谦逊拒绝等
- 支持忠诚、时机等拒绝原因

### 3. 罢免对话 (Recall)
- 7种罢免场景
- 礼貌罢免、感谢罢免、无奈罢免等
- 体现不同的罢免原因和态度

## 轮流对话流程

### 显示序列
1. **第一轮**: 显示君主头像和对话文本
2. **第二轮**: 君主对话结束后，显示军师头像和回应
3. **完成**: 军师对话结束后，记录游戏事件

### 技术实现
- 使用 `tupianwenziPlugin` 显示对话界面
- 通过 `SetCloseFunction` 设置对话结束回调
- 支持头像切换和文本轮流显示

## 配置文件示例

```xml
<DialogueEntry>
  <Type>Default</Type>
  <LeaderText>久闻先生大名，今日得见，果然名不虚传，愿请先生为我军师。</LeaderText>
  <AdvisorText>主公礼贤下士，某深受感动，愿献微薄之力。</AdvisorText>
  <MinLeaderIntelligence>60</MinLeaderIntelligence>
  <MinAdvisorIntelligence>85</MinAdvisorIntelligence>
</DialogueEntry>
```

## 集成点

### 1. 菜单集成
- 建筑左键菜单 → 君主 → 军师管理 → 任命军师
- 移除了独立的军师按钮和菜单

### 2. 代码集成
- `ScreenManager.cs` - 修改了 `FrameFunction_Faction_AppointAdvisor()` 方法
- `MGSContextMenu.cs` - 添加了新菜单项的处理
- `ContextMenuData.xml` - 更新了菜单配置

## 扩展性

### 1. 新增对话类型
- 在配置文件中添加新的 `DialogueEntry`
- 支持更复杂的匹配条件

### 2. 个性化匹配
- 可扩展性格匹配逻辑
- 支持更多人物属性匹配

### 3. 多语言支持
- 配置文件支持不同语言版本
- 对话文本可本地化

## 使用方法

1. **玩家操作**: 点击建筑 → 君主 → 军师管理 → 任命军师
2. **选择候选人**: 从候选人列表中选择
3. **观看对话**: 系统自动播放君主和军师的轮流对话
4. **完成任命**: 对话结束后完成任命流程

## 技术特点

- **配置驱动**: 对话内容完全由配置文件控制
- **智能匹配**: 根据人物属性智能选择合适对话
- **轮流显示**: 真实模拟君主和军师的对话过程
- **可扩展性**: 易于添加新对话和匹配条件
- **集成性**: 完全集成到游戏的菜单和UI系统中
