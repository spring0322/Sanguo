## 当前实现

### 1. 配置文件
- **Content/Data/AdvisorConvinceDialogues.xml**: 包含5个成功率等级的对话模板

### 2. 对话管理器
- **AdvisorConvinceDialogueManager.cs**: 简化版本，避免复杂的XML解析
- 直接使用硬编码的对话内容
- 提供成功率到对话的映射

### 3. 集成点
- 在 `FrameFunction_Architecture_AfterGetConvinceDestinationPerson()` 中集成
- 选择说服目标后触发军师对话
- 当前先输出到调试日志，然后正常执行说服

## 核心代码

```csharp
private void ShowSimpleAdvisorDialogue(Person targetPerson)
{
    try
    {
        // 简单的成功率计算
        int successRate = 50; // 默认成功率
        
        // 获取对话内容
        string dialogue = AdvisorConvinceDialogueManager.GetFullDialogue(targetPerson, successRate);
        
        // 输出到调试日志
        System.Diagnostics.Debug.WriteLine("[军师对话] " + dialogue);
        
        // 执行原始的说服逻辑
        foreach (Person person in this.CurrentPersons)
        {
            person.GoForConvince(targetPerson);
        }
        Session.MainGame.mainGameScreen.PlayNormalSound("Content/Sound/Tactics/Outside");
    }
    catch (Exception ex)
    {
        // 出错时执行原始逻辑
        // ...
    }
}
```
