# 军师谏言系统三大问题修复完成报告

## 修复概述
成功修复了军师谏言事件系统的三个关键问题，提升了用户体验和功能完整性。

## 问题1：对话框混乱 - 添加选择框功能
### 问题描述
- 原来的对话框没有选择选项，直接跳转到相关界面
- 用户无法选择是否要查看推荐内容

### 修复方案
**文件**: `WorldOfTheThreeKingdoms/GameManager/AdvisorAdviceEventSystem.cs`

#### 1. 修改对话显示逻辑
```csharp
// 根据建议类型决定是否需要选择框
if (suggestion == AdvisorSuggestionKind.PersonRecruit || suggestion == AdvisorSuggestionKind.LoyaltyWarning)
{
    // 需要选择的建议 - 显示确认对话框
    gameScreen.Plugins.tupianwenziPlugin.SetConfirmationDialog(
        gameScreen.Plugins.ConfirmationDialogPlugin,
        new GameDelegates.VoidFunction(() => HandleAdviceCallback(gameScreen, faction, suggestion, advisor)),
        null  // 选择"否"时不执行任何操作
    );
    gameScreen.Plugins.ConfirmationDialogPlugin.SetPosition(ShowPosition.Center);
}
```

#### 2. 修改对话文本
```csharp
case AdvisorSuggestionKind.PersonRecruit:
    return prefix + "主公，某发现附近有贤才在野，建议派人前去招揽！\n\n是否查看推荐人选？";

case AdvisorSuggestionKind.LoyaltyWarning:
    return prefix + "主公，某观察到部分将领忠诚度有所下降，需多加关注！\n\n是否查看相关武将？";
```

### 修复效果
- ✅ 人才招募和忠诚度警告现在显示"是/否"选择框
- ✅ 只有选择"是"才会跳转到相关界面
- ✅ 选择"否"直接结束对话，不执行任何操作
- ✅ 敌军预警仍然是纯信息提示，无需选择

## 问题2：事件优先级混乱 - 其他事件优先执行
### 问题描述
- 军师谏言与其他游戏事件同时触发，造成界面冲突
- 需要让其他事件先完成，再显示谏言

### 修复方案
**文件**: 
- `WorldOfTheThreeKingdoms/GameScreens/MGSDate.cs`
- `WorldOfTheThreeKingdoms/GameScreens/MainGameScreen.cs`

#### 1. 修改事件触发顺序
```csharp
private bool Date_OnDayStarting()
{
    if (!Session.Current.Scenario.Threading)
    {
        // 先执行基础的日期开始事件
        Session.Current.Scenario.DayStartingEvent();

        // 标记需要检查军师谏言，但延迟到Update中执行
        _needAdviceCheck = true;
        _adviceCheckDelay = 0;

        return true;
    }
    return false;
}
```

#### 2. 添加延迟检查机制
```csharp
// 处理延迟的军师谏言检查
if (_needAdviceCheck)
{
    _adviceCheckDelay++;
    if (_adviceCheckDelay >= ADVICE_CHECK_DELAY_FRAMES)
    {
        _needAdviceCheck = false;
        _adviceCheckDelay = 0;
        
        // 执行军师谏言检查
        try
        {
            GameManager.AdvisorAdviceEventSystem.CheckDailyAdvice(this);
        }
        catch (Exception ex)
        {
            System.Diagnostics.Debug.WriteLine($"[DelayedAdviceCheck] 军师谏言检查失败: {ex.Message}");
        }
    }
}
```

### 修复效果
- ✅ 军师谏言延迟3帧执行，确保其他事件先完成
- ✅ 避免了与部队AI、建筑状态重置等基础事件的冲突
- ✅ 保持了事件系统的稳定性和可预测性
