# 军师对话系统和绘制区域错误最终修复报告

## 🎯 问题总结

用户报告了两个持续存在的问题：
1. **绘制区域无效错误**: `[CacheManager] 绘制区域无效: {X:1055 Y:590 Width:0 Height:0}`
2. **军师对话框不显示**: 点击策略后没有弹出对话框，直接跳转到人员选择

## ✅ 修复方案

### 1. 军师对话系统修复 🔧

**问题根源**: TriggerAdvisorAdvice方法使用了错误的SetGameObjectBranch调用模式

**修复内容**:
```csharp
// 修复前：使用4参数模式（不工作）
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker,                           // 说话人
    speaker,                           // 游戏对象
    TextMessageKind.AdvisorAdvice,     // 消息类型
    "AdvisorAdvice"                    // 分支名称
);

// 修复后：使用6参数模式（参考工作的对话系统）
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker,                           // 说话人
    speaker,                           // 游戏对象
    TextMessageKind.AdvisorAdvice,     // 消息类型
    "AdvisorAdvice",                   // 分支名称
    "junshi.jpg",                      // 图片文件名
    "junshi"                           // 声音文件名
);
```

**参考成功案例**: 
- `MGSPersonText.cs` 中的工作对话实现
- 所有成功的对话都使用6参数SetGameObjectBranch模式

### 2. 绘制区域无效错误增强调试 🔍

**问题分析**: 
- 错误检测代码位于 `CacheManager.cs` 第827-830行和879-882行
- 大部分UI组件已经使用 `Math.Max(1, calculatedValue)` 模式修复
- 仍有少数边缘情况可能创建零尺寸矩形

**修复内容**:
```csharp
// 增强错误检测，提供详细调试信息
if (rec.Width <= 0 || rec.Height <= 0)
{
    System.Diagnostics.Debug.WriteLine($"[CacheManager] 绘制区域无效: {rec}");
    // 提供更详细的调试信息
    System.Diagnostics.Debug.WriteLine($"[CacheManager] 调用堆栈: {Environment.StackTrace}");
    return;
}
```
