# 军师感知系统完整实现报告

## 系统概述

成功实现了完整的军师感知系统，包含用户提供的所有方法以及额外的增强功能。该系统模拟了军师根据自身智力和性格对他人忠诚度的观测和判断过程。

## 核心功能实现

### 1. 基础感知方法 `GetPerceivedLoyalty`

```csharp
public static int GetPerceivedLoyalty(Person advisor, Person target)
```

**核心特性**：
- ✅ **固定种子机制**：`advisor.ID * 1000 + target.ID` 确保同一组合的偏差永远固定
- ✅ **智力影响准确度**：智力越高，误差范围越小
- ✅ **神算特殊处理**：智力100的军师能看到真实值
- ✅ **自我认知**：军师看自己的忠诚度总是准确的

**算法逻辑**：
```
误差范围 = 100 - 军师智力
固定种子 = 军师ID × 1000 + 目标ID
偏差值 = 固定随机数(-误差范围, +误差范围)
感知值 = 真实忠诚度 + 偏差值 (限制在0-100)
```

### 2. 性格偏向方法 `GetBiasedLoyalty`

```csharp
public static int GetBiasedLoyalty(Person advisor, Person target)
```

**性格影响机制**：

#### 仁德型 (CharacterKindID = 0)
- **特点**：容易把坏人看成好人
- **逻辑**：目标忠诚度 < 80 时，感知值 +10
- **历史原型**：刘备、孔融等仁德之士

#### 多疑型 (CharacterKindID = 1)  
- **特点**：容易把好人看成坏人
- **逻辑**：目标忠诚度 > 90 时，感知值 -15
- **历史原型**：曹操、司马懿等多疑君主

#### 莽撞型 (CharacterKindID = 2)
- **特点**：极端的两极分化判断
- **逻辑**：感知值 > 50 时 +20，否则 -20
- **历史原型**：张飞、许褚等直性子武将

#### 狡诈型 (CharacterKindID = 3)
- **特点**：关系影响判断
- **逻辑**：关系好的 +5，陌生的 -5
- **历史原型**：贾诩、郭嘉等精明谋士

### 3. 显示方法 `GetLoyaltyString`

```csharp
public static string GetLoyaltyString(Person advisor, Person target)
```

**智力分级显示**：

#### 高智力 (≥95)：精确数值
- 显示：`"75"` (具体数字)
- 适用：诸葛亮、司马懿等顶级谋士

#### 中等智力 (80-94)：模糊区间
- 显示：`"70~80"` (±5的区间)
- 适用：荀彧、庞统等优秀谋士

#### 低智力 (<80)：文字描述
- `"誓死效忠"` (≥90)
- `"尽忠职守"` (70-89)
- `"心存疑虑"` (50-69)
- `"心怀鬼胎"` (<50)

## 技术实现亮点

### 1. 固定种子机制

**问题解决**：
- ❌ 传统随机：每次查看结果都不同，"刷新就变"
- ✅ 固定种子：同一军师看同一人，结果永远一致

**实现方式**：
```csharp
int seed = advisor.ID * 1000 + target.ID;
Random stableRandom = new Random(seed);
```

### 2. 分层设计架构

```
GetLoyaltyString()          // 用户界面层
       ↓
GetBiasedLoyalty()         // 性格修正层  
       ↓
GetPerceivedLoyalty()      // 基础感知层
       ↓
target.Loyalty             // 真实数据层
```

### 3. 完整的错误处理

- 所有方法都包含 try-catch 块
- 详细的调试日志记录
- 优雅的降级处理
- 空值安全检查

### 4. 性能优化

- 静态方法设计，无需实例化
- 最小化计算复杂度
- 缓存友好的算法设计
