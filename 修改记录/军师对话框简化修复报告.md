# 军师对话框简化修复报告

## 修复的问题

### 问题1：对话框文字错乱，内容过于复杂
**症状**：对话框显示的文字混乱，句子太多，内容冗长
**原因**：对话内容包含过多详细信息和具体成功率数字

### 问题2：选择"否"后弹出额外对话框
**症状**：选择"否"后还会显示结束对话，用户体验不佳
**原因**：回调函数中调用了`ShowConvinceEndDialog`方法

## 修复方案

### 修复1：简化对话内容，使用模糊成功率模板

#### 新增方法：GetSimpleAdvisorDialogue
```csharp
private string GetSimpleAdvisorDialogue(int successRate, string targetName, bool isSupport)
{
    string baseDialogue;
    
    if (successRate <= 0)
    {
        baseDialogue = "一定不能成功，建议换个人或者时机。";
    }
    else if (successRate <= 33)
    {
        baseDialogue = "成功机会微乎其微。";
    }
    else if (successRate <= 66)
    {
        baseDialogue = "有一定的成功几率。";
    }
    else if (successRate <= 99)
    {
        baseDialogue = "成功概率很高。";
    }
    else
    {
        baseDialogue = "万无一失。";
    }
    
    return $"主公，说服{targetName}一事，{baseDialogue}";
}
```

#### 5个成功率模板
1. **0%**: "一定不能成功，建议换个人或者时机。"
2. **1-33%**: "成功机会微乎其微。"
3. **34-66%**: "有一定的成功几率。"
4. **67-99%**: "成功概率很高。"
5. **100%**: "万无一失。"

#### 对话格式统一
- **军师支持**：`"主公，说服{目标}一事，{成功率描述}。"`
- **军师劝阻**：`"主公，说服{目标}一事，{成功率描述}。"`

### 修复2：选择"否"直接结束，不弹额外对话框

#### 军师支持对话 - "否"按钮

## 用户体验改进

### ✅ 对话内容简化
- 去除冗长的分析描述
- 使用模糊但清晰的成功率描述
- 统一对话格式，易于理解

### ✅ 交互流程优化
- 选择"否"直接结束，无额外弹窗
- 选择"是"正常进入执行人员选择
- 减少不必要的对话层级

### ✅ 显示效果改善
- 避免文字错乱问题
- 对话框内容适中，不会过长
- 保持军师对话的权威性和简洁性
