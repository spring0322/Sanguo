# 军师谏言系统使用说明

## 概述

军师谏言系统已成功整合到现有的军师头像菜单中，提供智能的战略建议和预警功能。系统包含准确率机制，军师智力会影响建言的准确性。

## 功能特性

### 1. 军师建议类型 (AdvisorSuggestionKind)

```csharp
public enum AdvisorSuggestionKind
{
    None = 0,
    EnemyAttack = 1,      // 敌军来袭预警
    PersonRecruit = 2,    // 发现在野武将（推荐登庸）
    InternalAffair = 3,   // 内政建议（如：钱粮不足）
    LoyaltyWarning = 4,   // 武将忠诚度过低警告
    DisasterWarning = 5,  // 灾害预警
    // ... 其他类型
}
```

### 2. 核心方法

#### Faction.GetCurrentSuggestion()
```csharp
/// <summary>
/// 获取当前的军师建议
/// </summary>
public AdvisorSuggestionKind GetCurrentSuggestion()
{
    if (this.Advisor == null) return AdvisorSuggestionKind.None;

    // 1. 优先检查敌情 (智力越高，预警范围越大)
    if (AdvisorSuggestionSystem.CheckEnemyApproaching(this, this.Advisor.Intelligence)) 
        return AdvisorSuggestionKind.EnemyAttack;

    // 2. 检查是否有强力在野武将
    if (AdvisorSuggestionSystem.CheckUnfoundPerson(this)) 
        return AdvisorSuggestionKind.PersonRecruit;

    // 3. 检查忠诚度 (智力低可能漏报)
    if (AdvisorSuggestionSystem.CheckLoyaltyIssues(this) && 
        GameObjects.GameObject.Random(100) < this.Advisor.Intelligence) 
        return AdvisorSuggestionKind.LoyaltyWarning;

    return AdvisorSuggestionKind.None;
}
```

#### Faction.IsAdviceAccurate() - 新增准确率系统
```csharp
/// <summary>
/// 军师建言准确率计算
/// </summary>
public bool IsAdviceAccurate(int difficulty = 0)
{
    if (this.Advisor == null) return false;

    // 智力100必中
    if (this.Advisor.Intelligence >= 100) return true;

    // 智力70-99，准确率线性递增
    // 例如：智力70时准确率60%，智力95时准确率90%
    int baseChance = 60 + (int)((this.Advisor.Intelligence - 70) * 1.5);
    
    // 考虑难度调整
    baseChance -= difficulty;
    
    // 限制在合理范围内
    baseChance = Math.Max(10, Math.Min(95, baseChance));
    
    return GameObjects.GameObject.Random(100) < baseChance;
}
```

### 3. 准确率计算规则

#### 智力与准确率对照表
| 军师智力 | 基础准确率 | 说明 |
|----------|------------|------|
| 100 | 100% | 智力满值，建言必定准确 |
| 95 | 97.5% | 顶级智力，极高准确率 |
| 90 | 90% | 优秀智力，高准确率 |
| 85 | 82.5% | 良好智力，较高准确率 |
| 80 | 75% | 中等智力，一般准确率 |
| 75 | 67.5% | 基础智力，基础准确率 |
| 70 | 60% | 最低有效智力 |
| <70 | 10-60% | 智力过低，准确率很低 |

#### 难度调整
- `difficulty` 参数可以降低准确率，增加挑战性
- 每点难度降低1%准确率
- 最终准确率限制在10%-95%之间

### 4. 检查方法详解

#### 敌军预警 (CheckEnemyApproaching)
- **智力影响**: 军师智力越高，预警范围越大
- **计算公式**: 检测范围 = 智力 ÷ 10
- **示例**: 智力90的军师可以检测9格范围内的敌军

#### 人才发现 (CheckUnfoundPerson)
- **条件**: 发现能力值总和 > 200 的在野武将
- **建议**: 推荐玩家派人招揽

#### 忠诚度警告 (CheckLoyaltyIssues)
- **条件**: 发现忠诚度 < 60 的武将
- **智力影响**: 军师智力越高，发现概率越大

## 使用方式

### 1. 通过军师头像菜单
1. 点击右上角的军师头像
2. 选择"军师谏言"选项
3. 系统会自动分析当前形势并显示相应建议
4. 建议的准确性取决于军师智力

### 2. 程序调用
```csharp
// 获取当前玩家的军师建议
var faction = Session.Current.Scenario.CurrentPlayer;
var suggestion = faction.GetCurrentSuggestion();

// 检查建议是否准确
bool isAccurate = faction.IsAdviceAccurate();

switch (suggestion)
{
    case AdvisorSuggestionKind.EnemyAttack:
        if (isAccurate)
        {
            // 准确的敌军预警
        }
        else
        {
            // 误报或漏报
        }
        break;
    // ... 其他情况
}
```

## 谏言文本示例

### 准确的建言

#### 敌军来袭
> "主公，据某观察，敌军正在向我方逼近！请速做防备！"

#### 发现人才
> "主公，某发现附近有贤才在野，建议派人前去招揽！"

#### 忠诚度警告
> "主公，某观察到部分将领忠诚度有所下降，需多加关注！"

> "主公，当前人才济济，暂无招揽之需。"

#### 忠诚度误判
> "主公，将士们忠心耿耿，无需担忧。"

### 无建议
> "主公，当前形势尚好，可按既定方针继续行事。"


### 准确率系统特性

1. **智力依赖**: 军师智力直接影响建言准确率
2. **线性递增**: 智力70-99之间，每点智力增加1.5%准确率
3. **上限保护**: 即使智力100，也保留5%的不确定性
4. **下限保护**: 最低准确率不低于10%
5. **难度调整**: 支持通过difficulty参数调整挑战性

### 与现有系统的关系

- **EffectiveIntelligenceSystem**: 基于君主+军师的有效智力
- **IsAdviceAccurate**: 专门针对军师智力的准确率
- **两者互补**: 可以根据不同场景选择使用

## 注意事项

1. **军师依赖**: 所有功能都需要先任命军师才能使用
2. **智力影响**: 军师智力会影响预警范围、发现概率和建言准确率
3. **随机性**: 准确率计算包含随机因素，增加游戏趣味性
4. **平衡性**: 准确率限制在合理范围内，避免过于极端
5. **性能优化**: 建议在回合开始时缓存结果，避免频繁计算
