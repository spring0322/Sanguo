# 军师对话系统测试报告

## 问题分析

用户反馈军师策略建议没有弹出对话框，直接跳转到人员选择界面。

## 修复内容

### 1. 对话框调用方式修正 ✅
**问题**: 使用了错误的6参数版本的 `SetGameObjectBranch`
**修复**: 改为使用工作的4参数版本

```csharp
// 修复前 (错误的6参数版本)
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker, speaker, TextMessageKind.AdvisorAdvice, 
    "AdvisorAdvice", "AdvisorAdvice.jpg", ""
);

// 修复后 (正确的4参数版本)
this.Plugins.tupianwenziPlugin.SetGameObjectBranch(
    speaker, speaker, TextMessageKind.AdvisorAdvice, "AdvisorAdvice"
);
```

### 2. TextMessageKind枚举值添加 ✅
在 `TextMessageKind.cs` 中添加了：
```csharp
AdvisorAdvice, // 130 - 军师策略建议
```

### 3. 绘制区域错误修复 ✅
修复了Column.cs中的零宽度Rectangle问题：
```csharp
// 修复前
this.Text.Position = new Rectangle(0, 0, 0, tabList.columnheaderHeight);

// 修复后
this.Text.Position = new Rectangle(0, 0, Math.Max(1, 0), tabList.columnheaderHeight);
```

## 工作流程

修复后的军师策略建议流程：
1. 用户点击策略菜单（搜索、流言等）
2. 调用 `TriggerAdvisorAdvice()` 方法
3. 显示军师建议对话框（使用正确的4参数模式）
4. 用户点击确认关闭对话框
5. 触发回调函数，进入人员选择界面

## 关键修复点

### 对话框显示逻辑
```csharp
// 设置说话人的文本内容
speaker.TextResultString = adviceText;

// 设置对话框关闭后的回调函数
this.Plugins.tupianwenziPlugin.SetCloseFunction(delegate

    ShowStrategyPersonSelection(strategy, null);

// 显示事件对话框 - 使用正确的4参数模式

this.Plugins.tupianwenziPlugin.SetPosition(ShowPosition.Bottom, this);

```

### 简化的建议文本
为每种策略提供了合适的军师建议：
- 搜索：派遣能人搜索，或可有所收获
- 流言：流言惑众需谨慎行事，三人成虎不可小觑
- 破坏：破坏敌设施可削弱其实力，兵不厌诈
- 煽动：煽动民心需察言观色，民心可用但需时机
- 暗杀：暗杀风险极大需三思，此计凶险成败难料
- 劫牢：劫牢救人义之所在，救人一命胜造七级浮屠
- 说服：以德服人方为上策，招贤纳士壮我军威
- 情报：知己知彼百战不殆，情报为先方能制胜

## 测试建议

1. **基本功能测试**:
   - 进入游戏，选择有军师的势力
   - 右键点击建筑，选择策略菜单
   - 验证是否显示军师建议对话框

2. **对话框内容测试**:
   - 检查对话框是否显示正确的军师建议文本
   - 验证说话人是否为军师或君主

3. **流程完整性测试**:
   - 确认对话框关闭后正确进入人员选择界面
   - 测试不同策略类型的建议文本

4. **绘制错误测试**:
   - 观察控制台输出，检查是否还有绘制区域无效错误
   - 特别关注坐标1059,593附近的错误

## 预期结果

修复后，用户点击策略菜单时应该：
1. 首先看到军师建议对话框
2. 对话框显示相应的策略建议文本
3. 点击确认后进入人员选择界面
4. 不再出现绘制区域无效错误

如果对话框仍然不显示，可能需要进一步检查：
- TextMessageKind.AdvisorAdvice是否正确注册
- tupianwenziPlugin是否正常工作
- 是否有其他异常阻止对话框显示
