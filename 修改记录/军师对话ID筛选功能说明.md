# 军师对话ID筛选功能说明

## 功能概述

军师任命对话系统现在支持严格的ID和性格类型筛选，确保专属对话只能被指定的角色使用。

## 主要改进

### 1. 严格筛选逻辑
- **ID匹配**：如果配置中指定了 `LeaderID` 或 `AdvisorID`，只有完全匹配的角色才能使用该对话
- **性格类型匹配**：如果配置中指定了 `LeaderKind` 或 `AdvisorKind`，只有匹配的性格类型才能使用
- **不匹配直接淘汰**：任何不满足限制条件的对话条目都会被直接排除，不会参与评分

### 2. 详细调试信息
系统现在会输出详细的调试信息，包括：
- 角色的实际ID和性格类型
- 每个对话条目的匹配分数计算过程
- 最终选择的对话内容

### 3. 测试配置
在 `AdvisorDialogueTemplate.xml` 中添加了测试条目：
- 特定ID对话（LeaderID="1" AdvisorID="2"）
- 特定性格类型对话（LeaderKind="1", AdvisorKind="2"）
- 刘备和诸葛亮的专属对话（LeaderKind="635" AdvisorKind="289"）

## 配置文件结构

```xml
<Entry Type="Default" LeaderKind="635" AdvisorKind="289">
  <LeaderText>备虽驽钝，然信义著于四海。先生若肯出山，备当师礼事之，共图大业。</LeaderText>
  <AdvisorText>亮感皇叔三顾之恩，敢不竭股肱之力，鞠躬尽瘁，死而后已！</AdvisorText>
</Entry>
```

### 支持的筛选条件
- `LeaderID`: 特定君主ID
- `AdvisorID`: 特定军师ID  
- `LeaderKind`: 君主性格类型
- `AdvisorKind`: 军师性格类型
- `MinIntelligence/MaxIntelligence`: 智力范围
- `MinAge/MaxAge`: 年龄范围
- `MinLoyalty/MaxLoyalty`: 忠诚度范围
- `MinCommand`: 最低统率
- `MinPolitics`: 最低政治
- `HighAmbition`: 高野心要求
- `Relation`: 关系类型（如"Hate"）

## 技术实现

### 核心文件
1. **DialogueManager.cs** - 对话匹配和筛选逻辑
2. **AdvisorAppointmentSystem.cs** - 任命系统集成
3. **ScreenManager.cs** - 任命处理流程
4. **AdvisorDialogueTemplate.xml** - 对话配置文件

### 匹配算法
1. 遍历所有候选对话条目
2. 对每个条目计算匹配分数
3. 不满足限制条件的条目直接返回0分（淘汰）
4. 满足条件的条目根据匹配程度获得分数
5. 选择最高分的对话，如有多个同分则随机选择

### 分数权重
- ID完全匹配：100分
- 性格类型匹配：50分
- 智力匹配：20分
- 忠诚度匹配：15分
- 年龄匹配：10分
- 统率/政治匹配：10分
- 关系匹配：30分

## 故障排除

### 如果专属对话仍然被其他角色使用
1. 检查角色的实际ID和性格类型（查看调试输出）
2. 确认配置文件中的ID和性格类型是否正确
3. 检查是否有其他更高分的通用对话被选中

### 如果没有看到调试输出
1. 确保游戏在Debug模式下运行
2. 检查控制台窗口是否可见
3. 尝试在Visual Studio中运行以查看调试输出
