# 军师按钮鼠标坐标问题修复指南

## 🔍 问题分析

从调试信息可以看出：
- **按钮区域**: {X:1510 Y:60 Width:80 Height:80}
- **鼠标位置**: {X:1919 Y:-23}

**问题**：鼠标Y坐标是-23（负数），说明鼠标坐标获取有问题。

## 🔧 修复方案

### 1. 鼠标坐标验证和修复
```csharp
// 修复鼠标坐标 - 确保坐标在合理范围内
if (mousePos.X < 0 || mousePos.Y < 0 || mousePos.X > 3000 || mousePos.Y > 3000)
{
    // 鼠标坐标异常，使用上一帧的坐标或默认坐标
    if (prevMouse.X >= 0 && prevMouse.Y >= 0)
    {
        mousePos = new Point(prevMouse.X, prevMouse.Y);
    }
    else
    {
        mousePos = new Point(800, 400); // 默认屏幕中心
    }
}
```

### 2. 按钮点击检测优化
```csharp
// 验证鼠标坐标是否有效
if (mousePos.X < 0 || mousePos.Y < 0 || mousePos.X > 3000 || mousePos.Y > 3000)
{
    return; // 鼠标坐标异常，跳过处理
}

// 检查按钮是否在屏幕可见区域内
if (buttonX < -100 || buttonY < -100 || buttonX > 2000 || buttonY > 1500)
{
    return; // 按钮位置异常，跳过处理
}
```

## 🎯 可能的原因

### 1. 窗口模式问题
- 游戏可能在全屏和窗口模式之间切换时出现坐标系统问题
- 建议在窗口模式下测试

### 2. 多显示器问题
- 如果使用多显示器，鼠标坐标可能跨屏幕计算
- 建议在主显示器上测试

### 3. DPI缩放问题
- Windows的DPI缩放可能影响坐标计算
- 建议检查显示设置
