## 🎯 核心问题

军师任免不生效的根本原因是：

1. **缓存问题**: Faction类中的`advisor`字段是私有缓存，设置`AdvisorID`后没有清空缓存
2. **属性同步问题**: `Advisor`属性的getter会检查缓存，如果缓存不为null就直接返回，不会根据新的`AdvisorID`重新获取
3. **缺少强制刷新**: 任命后没有强制刷新`advisor`缓存

## 🎯 总结

这个修复方案的核心是解决缓存同步问题。军师任免不生效的根本原因是Faction类中的advisor字段缓存没有正确更新，导致虽然AdvisorID被设置了，但Advisor属性仍然返回旧的值（通常是null）。

通过在AppointAdvisor方法中强制清空并重新设置advisor缓存，确保任命立即生效。同样，在罢免时也要清空缓存，确保罢免立即生效。

这个修复方案参照了AppointOfficer的处理方式，确保军师任免功能与其他任命功能保持一致的行为。

#### 匹配条件支持

#### 权重计算规则

```csharp
public int GetMatchScore(Person leader, Person advisor)
{
    if (Type == DialogueType.Bond)
    {
        if (leader.ID == LeaderID && advisor.ID == AdvisorID) return 1000;
        return -1; // 不匹配
    }

    if (Type == DialogueType.Personality)
    {
        int score = 0;
        bool conditionMet = false;

        // 性格匹配 +100分
        if (LeaderKind != -1)
        {
            if (leader.CharacterKindID != LeaderKind) return -1;
            score += 100;
            conditionMet = true;
        }

        // 智力范围匹配 +50分
        if (advisor.Intelligence < MinIntelligence || advisor.Intelligence > MaxIntelligence) return -1;
        if (MinIntelligence > 0 || MaxIntelligence < 999)
        {
            score += 50;
            conditionMet = true;
        }

        return conditionMet ? score : -1;
    }

    return 1; // Default类型
}
```

public static DialogueInfo GetAppointAdvisorDialogue(Person leader, Person advisor)
{
    try
    {
        // 从XML配置加载对话
        var config = DialogueConfigManager.LoadAppointmentDialogues();
        var entry = DialogueConfigManager.FindBestMatch(config, leader, advisor);

        if (entry != null)
        {
            dialog.LeaderText = entry.LeaderText?.Replace("{advisor}", advisor.Name) ?? "";
            dialog.AdvisorText = entry.AdvisorText?.Replace("{leader}", leader.Name) ?? "";
            return dialog;
        }
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"[DialogueGenerator] XML配置加载失败，使用默认对话: {ex.Message}");
    }

    // 回退到硬编码对话（保持向后兼容）
    return GetAppointAdvisorDialogueFallback(leader, advisor);
}
