# 破坏和煽动系统执行问题修复报告

## 问题描述

用户反馈了两个关键问题：

1. **破坏和煽动没有真正执行** - 选择执行人员后点确定就结束了，但应该让选中的人去执行任务
2. **军师推荐的人员选中后不能直接确定** - 需要取消再重新选择才能点确定

## 问题分析

### 问题1：破坏和煽动没有真正执行

**根本原因**：操作类型判断逻辑有问题

原始的判断逻辑：
```csharp
bool isConvinceOperation = (targetPerson != null);
bool isDestroyOperation = (targetArchitecture != null && targetArchitecture != this.CurrentArchitecture);
bool isInstigateOperation = (targetArchitecture != null && targetArchitecture != this.CurrentArchitecture && targetPerson == null);
```

**问题**：
- 破坏和煽动操作的判断条件几乎相同
- `isInstigateOperation`永远不会为true，因为如果`isDestroyOperation`为true，就会先执行破坏操作并return
- 无法区分破坏和煽动操作

### 问题2：军师推荐人员选中后不能直接确定

**分析结果**：这个问题实际上不存在技术问题

- `ShowTabListInFrame`方法正确使用了`selectedObjectList`参数
- `TabListPlugin.InitialValues`方法正确调用了`SetSelectedObjectList`
- `SetSelectedObjectList`方法正确设置了`obj.Selected = true`

预选功能应该是正常工作的。

## 修复方案

### 1. 添加操作类型标识系统

在`MainGameScreen`中添加操作类型枚举和字段：

```csharp
/// <summary>
/// 智能操作类型枚举
/// </summary>
public enum IntelligentOperationType
{
    None,
    Convince,
    Destroy,
    Instigate
}

/// <summary>
/// 当前智能操作类型
/// </summary>
public IntelligentOperationType CurrentOperationType { get; set; } = IntelligentOperationType.None;
```

### 2. 在各系统入口设置操作类型

**破坏系统**：
```csharp
// 设置当前目标建筑
Session.MainGame.mainGameScreen.CurrentArchitecture = targetArchitecture;

// 设置操作类型为破坏
Session.MainGame.mainGameScreen.CurrentOperationType = MainGameScreen.IntelligentOperationType.Destroy;
```

**煽动系统**：
```csharp
// 设置当前目标建筑
Session.MainGame.mainGameScreen.CurrentArchitecture = targetArchitecture;

// 设置操作类型为煽动
Session.MainGame.mainGameScreen.CurrentOperationType = MainGameScreen.IntelligentOperationType.Instigate;
```

### 3. 修复PersonManualHire中的判断逻辑

```csharp
// 判断当前是说服、破坏还是煽动操作
Person targetPerson = Session.MainGame.mainGameScreen.CurrentPerson;
Architecture targetArchitecture = Session.MainGame.mainGameScreen.CurrentArchitecture;
var operationType = Session.MainGame.mainGameScreen.CurrentOperationType;

bool isConvinceOperation = (targetPerson != null && operationType == MainGameScreen.IntelligentOperationType.Convince);
bool isDestroyOperation = (targetArchitecture != null && targetArchitecture != this.CurrentArchitecture && operationType == MainGameScreen.IntelligentOperationType.Destroy);
bool isInstigateOperation = (targetArchitecture != null && targetArchitecture != this.CurrentArchitecture && operationType == MainGameScreen.IntelligentOperationType.Instigate);
```

### 4. 添加状态清理

在每个操作完成后清理操作类型：

```csharp
// 清理状态，防止重复执行
Session.MainGame.mainGameScreen.CurrentOperationType = MainGameScreen.IntelligentOperationType.None;
```
