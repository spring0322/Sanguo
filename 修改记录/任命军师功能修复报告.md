# 任命军师功能修复报告

## 问题诊断
用户反馈任命军师功能没有效果，经检查发现问题所在。

## 根本原因
在`MGSContextMenu.cs`中，任命军师的调用使用了错误的候选人列表：

### 修复前（错误）：
```csharp
case ContextMenuResult.Person_Appointment_AppointAdvisor:
    // 这是一个假设的调用，你可以把 AppointmentAdvisor 的逻辑也加进来
    this.ShowTabListInFrame(UndoneWorkKind.Frame, FrameKind.Person, FrameFunction.AppointAdvisor, 
        false, true, true, false, 
        Session.Current.Scenario.CurrentFaction.AdvisorCandicate,  // ❌ 错误：使用全局当前势力
        null, "任命军师", "");
```

### 修复后（正确）：
```csharp
case ContextMenuResult.Person_Appointment_AppointAdvisor:
    this.ShowTabListInFrame(UndoneWorkKind.Frame, FrameKind.Person, FrameFunction.AppointAdvisor, 
        false, true, true, false, 
        this.CurrentArchitecture.BelongedFaction.AdvisorCandicate,  // ✅ 正确：使用当前建筑所属势力
        null, "任命军师", "");
```

## 修复内容

### 1. 候选人列表来源修正
- **修复前**: 使用`Session.Current.Scenario.CurrentFaction.AdvisorCandicate`
- **修复后**: 使用`this.CurrentArchitecture.BelongedFaction.AdvisorCandicate`

### 2. 移除误导性注释
- 移除了"这是一个假设的调用"的注释
- 确认这是正确的实现方式
