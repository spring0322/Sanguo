4. 在输出窗口的"显示输出来源"下拉菜单中选择"调试"

### 3. 可能的问题和对应日志

#### 问题1: 字体文件加载失败
**查找日志：**
```
[TextManager] 字体文件加载失败或为空: Content\Font\FZLB_GBK.TTF
```
**解决方案：** 检查字体文件是否存在于 `Content/Font/` 目录

#### 问题2: 字体初始化失败
**查找日志：**
```
[TextManager] 字体初始化失败，font为null
[TextManager] 字体初始化异常: XXXXX
```
**解决方案：** 字体文件可能损坏或格式不支持

#### 问题3: FontPair配置错误
**查找日志：**
```
[TextManager] FontPair无效: Name=null, Size=0，尝试使用默认值
[CacheManager] FontPair无效: Name=null, Size=0，尝试使用默认值
```
**解决方案：** FontPair配置被重置为默认值

#### 问题4: 文字绘制被跳过
**查找日志：**
```
[TextManager] 文本为空，跳过绘制
[TextManager] 字体为null，跳过绘制
```
**解决方案：** 检查传入的文本内容和字体状态

#### 问题5: 顶点绘制失败
**查找日志：**
```
[FontSystem] 跳过无效矩形 - 顶点: Rectangle, 纹理坐标: Rectangle
[FontSystem] 绘制顶点X失败: XXXXX
[FontSystem] 没有顶点需要绘制
```
**解决方案：** 字体纹理生成或顶点计算有问题

### 5. 临时解决方案

如果调试日志显示一切正常但文字仍不显示，可以尝试以下方案：

#### 方案A: 使用原生SpriteBatch.DrawString
在TextManager.DrawTexts方法中临时使用原生的DrawString：

```csharp
// 临时解决方案：使用原生DrawString
if (Session.Current.Font != null)
{
    Session.Current.SpriteBatch.DrawString(Session.Current.Font, te, drawPos, color, 0f, Vector2.Zero, scaleVector, SpriteEffects.None, drawDepth);
}
```

#### 方案B: 检查SpriteBatch状态
确认SpriteBatch在绘制文字时处于正确状态：

```csharp
// 检查SpriteBatch是否已经Begin
System.Diagnostics.Debug.WriteLine($"[TextManager] SpriteBatch状态检查完成");
```

### 7. 常见问题排查

#### Q: 看不到任何调试日志
A: 确保在Debug模式下运行，并在Visual Studio的输出窗口中选择"调试"

#### Q: 字体文件不存在
A: 检查项目的Content目录结构，确保字体文件被正确包含在项目中

#### Q: 字体初始化成功但文字不显示
A: 可能是SpriteBatch状态问题或顶点绘制问题，查看FontSystem的调试日志

#### Q: 顶点数量为0
A: 可能是文字内容为空或字体渲染计算有问题
