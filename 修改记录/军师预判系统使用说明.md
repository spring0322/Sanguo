# 军师预判系统使用说明

## 🎯 系统概述

成功实现了完整的军师预判系统，包含三大核心功能：
1. **人才招募预判** - 预测招募武将的成功率
2. **外交预判** - 预测外交行动的成功率  
3. **战斗预判** - 预测战斗的胜率

## 📁 文件结构

```
WorldOfTheThreeKingdoms/GameManager/
├── StrategistManager.cs     # 核心预判算法
└── StrategistUI.cs         # 预判结果显示界面
```

## 🔧 核心功能

### 1. 人才招募预判

```csharp
// 使用示例
var (bestRecruiter, result) = StrategistManager.PredictRecruitment(playerFaction, targetPerson);

Console.WriteLine($"推荐招募者: {bestRecruiter?.Name}");
Console.WriteLine($"成功率: {result.SuccessRate}%");
Console.WriteLine($"军师评语: {result.Comment}");
```

**算法考虑因素:**
- ✅ 招募者魅力值
- ✅ 目标武将忠诚度
- ✅ 双方关系（亲爱/厌恶）
- ✅ 智力差距
- ✅ 势力声望
- ✅ 目标年龄
- ✅ 特殊情况（势力衰落、君主亲征等）

### 2. 外交预判

```csharp
// 使用示例
var result = StrategistManager.PredictDiplomacy(playerFaction, targetFaction, "结盟");

Console.WriteLine($"外交成功率: {result.SuccessRate}%");
Console.WriteLine($"军师建议: {result.Comment}");
```

**算法考虑因素:**
- ✅ 双方实力对比
- ✅ 当前外交关系
- ✅ 历史互动记录

### 3. 战斗预判

```csharp
// 使用示例
var result = StrategistManager.PredictBattle(ourTroop, enemyTroop);

Console.WriteLine($"战斗胜率: {result.SuccessRate}%");
Console.WriteLine($"军师分析: {result.Comment}");
```

**算法考虑因素:**
- ✅ 双方兵力对比
- ✅ 士气状况
- ✅ 将领统率能力
- ✅ 兵种相克关系

## 🎮 游戏集成示例

### 在招募界面中使用

```csharp
// 在人物选择界面添加"军师预判"按钮
public void OnStrategistAdviceClick()
{
    if (selectedPerson != null)
    {
        var strategistUI = new StrategistUI();
        strategistUI.ShowRecruitmentPrediction(
            Session.Current.Scenario.CurrentPlayer, 
            selectedPerson
        );
    }
}
```

### 在外交界面中使用

```csharp
// 在外交选择界面添加预判功能
public void OnDiplomacyAdviceClick(string diplomacyType)
{
    if (targetFaction != null)
    {
        var strategistUI = new StrategistUI();
        strategistUI.ShowDiplomacyPrediction(
            Session.Current.Scenario.CurrentPlayer,
            targetFaction,
            diplomacyType
        );
    }
}
```

### 在战斗前使用

```csharp
// 在战斗确认界面添加预判
public void OnBattleAdviceClick()
{
    if (ourTroop != null && enemyTroop != null)
    {
        var strategistUI = new StrategistUI();
        strategistUI.ShowBattlePrediction(ourTroop, enemyTroop);
    }
}
```

## 🔍 智力影响系统

军师智力影响预测准确度：

- **智力 ≥ 90**: 预测极其准确，误差 ±2%
- **智力 70-89**: 预测较准确，误差 ±5%
- **智力 < 70**: 预测不够准确，误差 ±10%
- **无军师**: 只能给出50%的模糊预测
