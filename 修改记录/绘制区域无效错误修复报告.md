# 绘制区域无效错误修复报告

## 问题描述
用户报告游戏中出现以下绘制区域无效错误：
```
[CacheManager] 绘制区域无效: {X:1072 Y:587 Width:0 Height:0}
[CacheManager] 绘制区域无效: {X:1182 Y:695 Width:0 Height:0}
```

## 已完成的修复

### 1. 核心绘制系统修复 ✅
- **Animation.cs**: 已修复 `GetCurrentDisplayRectangle` 方法，使用 `Math.Max(1, width)` 确保最小1像素宽度
- **DantiaoLayer.cs**: 已修复技能条和生命条绘制，确保最小1像素宽度
- **NumericSetTexture.cs**: 已修复填充条绘制，确保最小1像素宽度
- **TroopTitle.cs**: 已修复士气条绘制方法 `shiqitiaokuandu`
- **ArchitectureDetail.cs**: 已修复士气条绘制方法

### 2. 军师策略对话系统修复 ✅

#### 问题分析
用户反馈军师策略建议没有显示对话框，直接跳转到人员选择界面。

#### 修复方案
1. **修正对话框调用方式**: 
   - 从错误的6参数版本改为正确的TextMessageKind模式
   - 参考工作的任命军师对话系统实现

2. **添加TextMessageKind枚举值**:
   ```csharp
   AdvisorAdvice, // 130 - 军师策略建议
   ```

3. **简化TriggerAdvisorAdvice方法**:
   - 移除对缺失类的依赖
   - 使用简化的建议文本生成
   - 确保对话框正确显示后再进入人员选择

#### 修复后的工作流程
```
策略菜单点击 → TriggerAdvisorAdvice() → 显示军师建议对话框 → 用户确认 → 人员选择界面
```
