1. 语言反馈规范 (Language)

全中文反馈：Agent 的所有解释、任务计划（Artifacts）、代码注释以及针对代码逻辑的讨论，必须统一使用中文进行。

2. 环境与语法约束 (Technical)

版本锁定：必须严格遵循 C# 7.3 语法规范。

❌ 严禁使用：record、switch 表达式、using 声明（不带大括号）、init 属性、可为空引用类型（T?）、Span<T> 等高版本特性。

✅ 必须使用：标准 class、传统的 switch 语句、显式作用域的 using 语句。

框架要求：代码必须完全兼容 MonoGame / XNA。处理图形、输入、音频时，优先调用 XNA 传统的生命周期 API。

内存优化：在 Update 或 Draw 等高频执行循环中，严禁进行不必要的堆内存分配（如 new 列表或对象），优先使用对象池或已有的局部变量。

3. 代码质量控制 (Quality)

逻辑严密性：严禁出现低级错误，如未处理的空引用、变量未初始化、死循环或计算溢出。

非破坏性修改：在不收到明确重构指令时，严禁修改现有的类结构、公共接口（Public API）或已优化的核心算法。

修改流程：在修改代码前，必须先列出中文计划说明“修改点”及“潜在影响”，获得确认后再执行。

4. 交付要求 (Delivery)

建议提供：每次完成代码修改或技术讨论后，必须提供 2-3 个关于代码优化或后续功能实现的技术方向选择。
