# AOT数据转换问题系统性修复规范

## 项目概述
解决.NET AOT升级后导致的数据序列化/反序列化问题，特别是游戏对象属性在运行时变为null的问题。

## 问题背景

### 当前症状
1. `BelongedFaction.Leader` 在运行时为null
2. `Person.IdealTendency` 在运行时为null  
3. 其他游戏对象的关联属性可能也存在类似问题
4. 这些问题在AOT编译环境下更容易出现

### 根本原因分析
AOT编译对反射和动态类型转换有限制，可能导致：
- JSON序列化/反序列化失败
- 对象关系重建失败
- 延迟加载属性未正确初始化
- 类型转换在AOT环境下失效
