# 游戏核心机制规范

**日期：** 2026-03-14  
**状态：** 强制执行

---

## 🎮 核心机制：半回合半即时

游戏分为两个明确阶段，任何AI逻辑、部队行为、UI交互的设计都必须遵守此机制。

### 战略阶段（操作面）
- `Date.IsRunning = false`
- 游戏时间**暂停**
- 玩家通过鼠标点击选择部队、下达命令（移动/攻击/计略/入城）
- AI势力在 `Faction.Run()` 中同步完成所有决策
- 部队命令通过 `Operated = true` + `Command = xxx` 标记，**不立即执行**

### 执行阶段（行动面）
- `Date.IsRunning = true`（由 `DateGo()` 触发）
- 游戏时间**推进**
- 玩家部队与所有AI部队**同时**在 `CurrentQueueTroopMove()` 队列中执行命令
- 执行完毕后设置 `OperationDone = true`
- 所有部队执行完毕后 `DateStop()` 结束本日

---

## 🔄 完整调用链

```
GameGo(gameTime)
│
├─ AfterDayPassed()                    ← 战略阶段
│  └─ Factions.RunQueue()
│     └─ Faction.Run()
│        ├─ [玩家势力] 等待玩家操作（Passed=true 后返回）
│        └─ [AI势力]
│           ├─ AIDiplomacy / AITechniques / AICapital ...（战略决策）
│           ├─ RunPersonnel / RunDomestic / RunMilitary（内政军事）
│           └─ AILegions → Legion.AI → TroopAI → Troop.AI（战术决策）
│
└─ [所有势力完成后]
   ├─ DateGo()                         ← 开始执行阶段
   ├─ CurrentQueueTroopMove()          ← 玩家+AI部队混合执行
   └─ DateStop()                       ← 结束执行阶段
```

---

## 🚦 关键状态标志

| 标志 | 含义 | 设置时机 |
|------|------|---------|
| `Date.IsRunning` | 是否处于执行阶段 | `DateGo()` → true，`DateStop()` → false |
| `Troop.Operated` | 部队是否已下达命令 | 玩家操作 或 `Troop.AI()` 中设置 |
| `Troop.OperationDone` | 部队是否已执行完毕 | `CurrentQueueTroopMove()` 中设置 |
| `Troop.Command` | 部队命令类型 | `SetCommand(TroopCommand.xxx)` |
| `Faction.Passed` | 势力是否完成回合 | 玩家点击"进行" 或 AI完成决策 |
| `Faction.AIFinished` | AI是否完成决策 | `Faction.Run()` 末尾设置 |

## ⚠️ 设计约束

### ✅ 正确的设计
- 战略阶段只设置命令，不执行移动
- 执行阶段不允许玩家下达新命令
- AI决策在 `Faction.Run()` 中完成（战略阶段）
- 部队移动在 `CurrentQueueTroopMove()` 中完成（执行阶段）

### ❌ 错误的设计
- 在操作面（战略阶段）直接触发部队移动动画
- 在执行阶段修改部队的 `Command`
- AI在执行阶段才开始决策目标
- 设置 `CurrentAIState` 导致操作面立即移动

---

## 📍 常见错误模式

```csharp
// ❌ 错误：操作面立即设置 CurrentAIState，导致部队瞬移
this.CurrentTroop.SetCommand(TroopCommand.Move);
this.CurrentTroop.CurrentAIState = TroopAIState.Marching;  // 不要这样！

// ✅ 正确：只设置 Command，让执行阶段的 CurrentQueueTroopMove 处理
this.CurrentTroop.SetCommand(TroopCommand.Move);
this.CurrentTroop.Operated = true;
// CurrentAIState 由 TroopListWithQueue.CurrentQueueTroopMove 在执行面设置
```

```csharp
// ❌ 错误：计略/战法选择目标前就设置 Operated，导致取消后仍消耗操作权
this.CurrentTroop.SetCommand(TroopCommand.Stratagem);
this.CurrentTroop.Operated = true;  // 不要在目标确认前设置！

// ✅ 正确：目标确认后才设置 Operated
this.CurrentTroop.SetCommand(TroopCommand.Stratagem);
// ... 玩家选择目标 ...
// 目标确认后：
this.CurrentTroop.Operated = true;
```
